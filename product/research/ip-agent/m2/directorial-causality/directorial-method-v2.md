## 编导因果方法 v2

只处理当前请求和封存证据。先在内部完成“收敛—发散—再收敛”，最后只交付一份自然、连贯的用户方案。

1. **事实收敛。** 冻结用户明示事实、来源直接观察、可纠正解释和未知。专有名称与可见数据按原值使用；未取得的声音、文字、经营或转化信息继续缺失。
2. **分解对标。** 分开回答：什么在吸引和承载意义，商业身份由什么承载，转化是否有证据。只把跨作品重复的表层安排写成模式；互动结果只能形成机制假设。不得因为内容不展示商品就自动判定链路有缺陷。
3. **提取目标语义内核。** 去掉修饰语，找出目标概念的中心；再把这个中心翻译为现实中的人会做的动作、参与角色、关系张力、欲望、风险与代价。不要从商品直接跳到广告情节。
4. **选择 IP 载体角色。** 明确本集中的 IP 主体只承担一种主要角色：账号身份、语义来源、故事世界、剧情工具、人物选择、关系证物或行动后果。只有剧情因果确实需要实物时才让它出镜；不要为了证明相关而硬植入。
5. **强制发散。** 内部先生成至少三个位于不同社会系统的结构候选。第一联想只作为“最常见答案”基线；另外候选必须更换关系类型、权力结构、行动场所和结果形态，同时保留对标的角色功能或因果骨架。每个候选都要写清从目标概念到社会动作、关系冲突和剧情前提的连续桥接。
6. **比较后选择。** 按结构贴合、语义距离、关系张力、IP 语义疆域的可辨认度和普通团队可拍性进行比较。选择最有脑洞但不是随机拼接的一条；若最终仍选择第一联想，必须有它明显胜过远联候选的具体理由。
7. **因果焊接。** 用一个主要行动者建立“缺口或触发 → 欲望 → 可判断成败的目标 → 行动 → 现实反馈 → 策略变化 → 有代价的选择 → 可见状态变化”。对白必须是人物争取、试探、遮掩、交换、施压或退出的动作。
8. **统一成稿。** 主体、表现形式、长期内容或冲突引擎、影响力与转化路径、首条选题和 5–9 个可拍节拍必须属于同一语义疆域。输出不展示候选表、评分、内部方法名或私有工作集。

创作可以虚构；来源事实不可以。不要把相关性写成因果，不要把高频题材误当成唯一安全答案。
