## 单向综合方法

下面六步只在内部依次形成一条决策链。上一步只向下一步交付必要结果；不得各写一份报告，也不得
让下游重新推翻上游已经负责的决定。

1. **对标机制。** 对每条证据先分开“观察到什么、它可能承担什么功能、为什么可能影响观众、
   哪些变量可以替换、哪些具体表达不能复制”。只有至少两条已检查作品重复出现，才能称为账号
   机制；互动量只能证明观察到的反应，不能单独证明原因。证据不足以确认重复机制时，保留为
   作品级假设并说明限制。根据覆盖范围选出一个最值得进入首条内容的已确认机制或作品级假设。
2. **IP 方向。** 基于用户目标、产品语义和上一步机制，确定一个 IP 主体、一个表达载体、希望观众
   在什么情境下记住或选择它、一个长期内容或冲突引擎，以及一条合理但不虚构经营事实的影响力
   与成交路径。只给一个主方向，并说清它的主要取舍；这里只产出首条内容简报，不另写脚本。
3. **观众反应。** 注意、情绪、分享和行动四层不要求全部使用；只选择真正会改变本集的机制，
   每层最多一个。把每个机制绑定到具体剧情节拍和可观察反应；不堆理论名词，不预测播放量，
   不用虚假悬念、羞辱或无依据争议换互动。
4. **欲望因果。** 冻结一个主要行动者，建立“触发或缺口 → 意识欲望 → 可判断成败的目标 → 行动
   策略 → 现实反馈 → 策略变化 → 有代价的选择 → 可见状态变化”。心理词必须落成动作；静音后仍
   应看得出谁想要什么、做了什么、遇到什么反作用以及结尾改变了什么。
5. **单集成稿。** 作为唯一成稿负责人，把前四步合并为一条陌生观众也能独立看懂的短视频。使用
   5–9 个动作节拍；每个节拍必须带来新信息、反馈、策略变化、选择或兑现。开头承诺本集问题，
   结尾兑现而不是突然停止；不要让旁白替代本应发生的行动。
6. **场景对白。** 只能在第五步已经确定的事件和节拍内完善场景，不另起第二条剧情。每场明确人物
   此刻想从对方那里得到什么、对方为何不给、策略如何变化、什么信息造成转向、离场时关系或信息
   如何改变。对白是争取、试探、遮掩、交换、施压或退出等行动，删除只向观众解释双方都知道之事
   的句子，并把最终对白回写进同一份成稿。
