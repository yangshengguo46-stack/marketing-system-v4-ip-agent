# Ark Managed Agent 模型对照（2026-08-04）

状态：`research_quarantined`

本记录回答一个有限问题：在同一个最小 IP 方向合同、同一组输入、零工具的
Ark Managed Agent 环境里，哪个候选模型质量更高，哪个更快。它不是现役能力验收，
也不更新产品台账。

## 对照条件

- 模型：`doubao-seed-2-1-pro-260628`、`doubao-seed-2-1-turbo-260628`、
  `doubao-seed-evolving-latest-version`；
- 三组固定输入：S2 礼数统筹者、S3 金工转译者、S4 阶段角色鼓手；
- 三组 Agent 使用逐字相同的 1,820 字节系统合同，输入分别为 384、405、473 字节；
- 同一个 cloud environment、相同 `standard` speed、相同 Agent version；
- 创建时显式传入 `--tool '[]'`，未附加 Skill、MCP、Vault、资源或 Session override；
- 九个 Session 的运行事件均为零工具调用，只出现用户消息、模型请求、thinking 和回答；
- Ark CLI 的 GET 响应会省略空的 Tools/Skills/MCP 字段，因此无法从静态回显区分
  空数组与未回显；九次实际运行零工具事件是当前最强运行证据。

Turbo 三题均最快，总耗时比 Pro 少 51.0%，比 Evolving 少 51.7%。Evolving 的
S3 出现 136.854 秒长尾，是 Turbo 同题的 4.20 倍。

Pro 的 S4 发生两段模型请求：第一段正常结束但没有生成最终 `agent.message`，第二段
才给出答案。事件没有 error 或工具调用，只能确认发生了内部续跑，不能从现有证据断言
具体病根。

显式系统合同和用户输入合计只有约 2.2 KB，但单请求 `input_tokens` 约 7,400，说明
Managed Agent 还注入了平台侧上下文。该环境适合版本化实验，但不能据此假定它就是
未来生产链路里最轻的调用方式。

## 独立盲审

先按匿名组评分、再揭示模型。质量满分 95，不计速度：

| 模型 | S4 | S2 | S3 | 平均 | 严格 JSON |
| --- | ---: | ---: | ---: | ---: | ---: |
| Evolving | 85 | 85 | 82 | **84.0** | **3/3** |
| Pro | 79 | 79 | 77 | 78.3 | 0/3 |
| Turbo | 75 | 65 | 71 | 70.3 | 1/3 |

评分维度为事实/本体边界、跨域关联与单一方向、双控制环、编导/内容方向、
可验证 pilot 和结构表达。

### Evolving

优点：本体边界、单一方向和内外双环最稳定，也是唯一三题都返回合法纯 JSON 的模型。
S2 能从急诊分诊、外交礼宾和剧本杀主持人迁移关系结构；S4 没有把照料者身份变成
育儿账号方向。

缺陷：仍会发生能力和职责升级——把“镜头恐惧”扩大为“不露脸”，把“能将纹理转成
金属作品”扩大为完整黄金制作能力，还补出“个人/工作室、交付获客责任”。部分 pilot
只是连续观察或同时更换多个内容，不是严格单变量实验。编导机制已经出现，完整故事感染力
尚未验证。

### Pro

优点：命名和远距离联想最有编导感，产生了“礼数救火队”“痕迹入金”等可记忆方向。

缺陷：三题都没有满足严格 JSON；S2 在明确没有客户案例时写入“亲历现场”“真实发生过”
和具体双方父母冲突；S3 擅自补充具体金工流程与产品形态；S4 又要求“不煽情、不讲故事、
不剪辑不美化”，事实保守反过来损伤了创作目标。S4 还多跑了一次模型请求。

### Turbo

优点：三题全都最快，输出最短，方向基本可用。

缺陷：更像标准运营建议，不像编导内核；跨域联想偏近邻，S2 过早把黄金选配塞进内容，
多个 pilot 同时改变题材、作品或其他条件，又使用没有基线支撑的任意数字阈值。严格 JSON
只通过 1/3。

## 本轮决策

用户于 2026-08-04 审阅对照结论后确认选择 Evolving。

1. **方向内核实验默认使用 Evolving。** 当前阶段质量优先，84.0 对 70.3 的差距不能用
   约 41 秒平均延迟换掉。
2. **Turbo 只作为快速对照组。** 它适合低风险整理、格式化和早期结构试跑，不负责最终
   IP 方向或故事判断。
3. **Pro 暂时淘汰。** 它的创意亮点没有抵消事实污染、非法 JSON 和额外耗时；不进入链路。
4. 下一轮只针对 Evolving 验证两个最小修订：禁止能力/材质/职责升级推断；让 pilot 真正
   只改变一个变量。不得追加长提示词或下游硬门掩盖问题。
5. 本轮只证明“最小方向编译”相对更好，尚未证明完整编导故事、真实视频证据、脚本、
   发布或经营闭环成立。
