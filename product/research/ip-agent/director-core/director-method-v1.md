# IP 编导概念方法 v1

> 研究隔离：本方法不得接入默认 Agent，不拥有产品事实，不写入方向状态，
> 也不得把结构完整度描述成创意质量已经通过。

目标不是替用户套一个行业人设，而是把真实主体、公众关系、语义结构和商业目标
编译成一个可证伪、可持续、可生产的 IP 方向假设。

## 一、先确定系统问题

先回答本次要改变哪一群公众对哪个对象的识别、记忆、信任、期待、偏好或行动。
把平台、内容数量和单条播放视为环境、干预或观测，不把它们写成 IP 本体。

分开四个锚点：

- 注意锚：公众为什么愿意停留；
- 信任锚：公众凭什么相信；
- 意义锚：公众最终把何种意义归因给谁；
- 交易锚：最终希望谁对什么采取行动。

四个锚点可以由不同实体承担，不能强迫一个人或一个商品包办全部功能。

## 二、建立本体和信息边界

人物、产品和组织是可运营主体。阶段身份、职业、家庭位置和镜头身份是带时间范围的
角色，不得把角色字符串当成人物本体。组织和产品可以有规则、功能、资源和业务目标，
但不能被赋予未经明确虚构的心理欲望。

区分运营者可控制的名称、符号、表达和行为，与公众实际形成的认知。前者不是后者的
事实证明；公众认知在没有观测时保持未知。

所有输入使用统一认知状态：`user_asserted`、`source_observed`、`derived`、
`hypothesized`、`creative`、`unknown`、`contradicted`。每个推导只引用更早的依据，
不把假设、虚构或缺失改写成事实。

## 三、按主体采用不同取材入口

- 人物主导：读取跨时间经历、明确欲望、已证明能力、关系、可见行动和生产限制；
  当前角色只提供资源、阻力或代价。
- 产品主导：读取使用事件、参与者、功能机制、替代方案、可观察证明和文化象征；
  欲望属于使用者或其他行动者。
- 组织主导：读取成员、规则、协作、真实选择、交付能力和公众接触面；
  故事行动者仍然是具体的人或明确虚构角色。

入口不同，中段共用同一个编导决策。一个业务可以设计多个账号或栏目，但单个账号或
系列必须明确主要载体及四锚分工。

## 四、先拆语义，再做关联

1. 识别中心概念、修饰语以及它们的关系；保留修饰信息，不能让修饰语吞掉中心，
   也不能为了找到中心而丢掉材料、时间、范围或价值属性。
2. 把名词还原成事件框架：谁在什么场景中对谁或什么采取什么行动，受到哪些规则、
   信息和关系约束，可能产生何种后果。
3. 暂时移除行业、职业和阶段身份标签，检查剩余的人、物、组织、欲望、能力和关系。
   信息不足时降级为待验证假设，不补写性格、过去或隐性动机。
4. 将角色放回，只允许它改变资源、阻力、代价、接触面或表现条件；若角色重新决定了
   人物全部内容命运，说明仍然被标签锁定。

## 五、强制远距离结构发散

先记录最顺手的近邻答案，把它当作固着基线而不是默认结论。随后形成三个属于不同社会
系统的候选，其中至少两个来自远领域。

远联不是随机拼词。每个候选必须明确：

- 原领域与目标领域各有哪些行动者；
- 保留了哪些关系和因果边；
- 替换了哪些表层人物、地点、道具和表达；
- 为什么适合当前主体的真实事实；
- 哪些部分仍只是创作假设。

高表面距离而没有关系同构是怪话；关系相同而表面没有替换是复制。

## 六、用营销和生产条件收敛

把创作者欲望、观众欲望和商业目标保存为三个不同集合。候选方向必须同时回答：

- 它依赖什么不可随意换名的真实能力、历史、资源、机制或选择；
- 观众在什么处境下会需要这种意义、判断、证明或体验；
- 为什么选择该主体而不是常见替代；
- 内容之后希望发生什么可观察行为；
- 商品、服务或组织在价值交换中承担什么功能；
- 该方向主动放弃什么；
- 当前人员、时间、地点、镜头和表演条件是否可持续。

生产限制可以改变屏幕载体和内容模式，不能偷偷改写人物经历或长期方向。产品不必每条
露出；只有当它被声明为关键动作、证物或结果时，移除它才必须改变因果。

## 七、只在需要时进入故事协议

账号层必须有长期变化或持续问题，但单条内容可选择故事、证明、教学、体验、仪式或混合。
采用故事或混合模式时，才强制建立：

```text
中心概念
→ 人会用它做什么
→ 这个动作改变哪段关系
→ 谁想把关系变成什么状态
→ 初始策略
→ 现实反馈
→ 策略变化
→ 不能兼得的选择及代价
→ 可见状态改变
→ 一句话故事
```

这条链称为因果桥。远领域候选只能向因果桥提供可迁移的关系和因果结构；写一句话故事前
必须删除来源领域的人名、职业、地点和道具，再把结构翻译回目标主体的真实世界。只列出
三个类比而没有完成这次翻译，不算编导联想。

因果桥至少回答：

- `semantic_action`：中心概念在人类世界中对应什么动作；
- `relationship_at_stake`：这个动作会改变信任、边界、地位、义务、归属或其他什么关系；
- `trigger`、`want`、`goal`：谁在什么触发下想把什么变成可判断成败的状态；
- `initial_tactic`、`feedback`、`strategy_change`：人物先怎么做，现实如何反作用，随后换了什么策略；
- `costly_choice`、`cost`、`state_change`：哪两样不能兼得，选择付出什么，结尾什么现实状态变了；
- `viewer_desire`：观众想确认哪个结果、真相或选择；
- `logline`：把以上因果压成一个句子，而不是堆主题词。

在压缩一句话故事前，必须先决定商业对象是否进入故事。这里只允许两种模式：

- `absent`：产品、服务、品牌或业务类别只负责帮助发现一个人的动作、关系和意义领地，
  随后从故事世界彻底退出；公众归因与商业承接留在故事外；
- `causal`：商业对象的独特用途、规则或后果实际改变了人物的行动、反馈、选择或状态，
  移除它或换成普通替代物会使因果链断裂或变成另一件事。

这是单集级的故事决定，不是账号永远露出或永远隐藏产品的策略。采用 `absent` 时，
`relationship_at_stake` 是语义分界线：一旦人的关系命题形成，中心概念、修饰语、材质属性
和商品联想就已完成任务，后续 `trigger` 到 `state_change` 只能读取人的关系矛盾，不能再从
商业对象取道具或解决方案。换句话说，语义种子必须在这里被消费掉，而不是换皮后进入剧情。

不允许第三种“顺手露出”模式。若商业对象虽然出现，却可被任意道具替换且事件照样成立，
它就是可替换植入，不是因果部件：要么删除它并采用 `absent`，要么重新设计因果使其成为
`causal`。这一决定必须记录为 `commercial_object_mode`，并用 `substitution_test` 说明替换或
移除后具体哪条因果边会改变；仅声称“有象征意义”不能通过替换测试。

一句话故事使用这个关系，不强迫固定措辞：

`当[触发]，[人物]为了[目标]先采取[策略]，但[反馈/反作用]迫使其在[不能兼得的选择]间
作出决定并承担[代价]，最终[可见状态改变]。`

没有发生过的人物、事件和结果可以用于虚构创作，但整条故事必须标记为 `creative`，并把
虚构部分写入 assumptions；真实事件则标记为 `source_observed` 并引用来源事实。不得把
创作情境写成亲历案例，也不得因为真实性边界而禁止故事。

故事世界与商业世界必须分开：

- 故事世界回答具体人物之间发生了什么，人物的欲望、行动、反馈、选择和状态改变都发生
  在这个世界；
- 商业世界回答这条故事让公众把什么能力或意义归因给运营主体，以及之后是否产生关注、
  咨询、试用、购买或其他行动；
- 商业目标可以筛选故事、决定系列范围和回收方式，但不能自动成为故事人物的目标、阻力、
  代价或结局；
- 除非本集明确讲运营者自己的经营事件，否则帐号、流量、平台、咨询和成交不得进入故事
  因果链，只能写在独立的业务连接中。

先让故事世界独立成立，再检查商业连接。故事不能靠结尾强塞商品或咨询成立，商业连接也
不能反向伪造故事人物的欲望。

一句话故事需要通过四个检查：去掉行业名后因果仍成立；商业对象符合已经声明的
`commercial_object_mode`，不存在可替换植入；静音后仍能看出目标、反作用、选择和结果；
结尾改变关系、身份、信息、能力、资源或规则中的至少一项。

非故事内容也必须说明观众问题、证据或体验如何改变公众关系，不能用虚构冲突替代真实证明。

## 八、压力测试和控制闭环

选定方向前生成十二个结构不同、无需热点的事件发生器。删除标题和行业名后，动作、关系、
问题和状态变化仍应具有差异；仅替换名词不算十二条。

再执行：标签移除、角色放回、热点消失、资源减少、主体换名、表现载体切换等变异测试。
最后只保留一个工作方向、主要权衡、一个单变量样片、观测窗口、成功与失败信号，以及根据
结果修订或淘汰方向的规则。

样片前只能称为“工作假设”或“试拍方向”。模型负责生成候选和解释，独立校验器负责检查
本体、引用、事实等级、四锚、候选多样性与可证伪性；模型不得自行宣布通过。
