# 编导语义发散方法 v2

本阶段只做语义路线，不写故事。目标不是把行业词换成漂亮栏目名，而是找到一个由当前主体事实
支撑、能够持续发生人类冲突的内容主体。

## 事实只能降格使用，不能升级使用

只读取输入 `facts`。`facts_used` 必须逐字复制事实。引用主体经历、频率、地点、能力、关系或结果时，必须沿用事实原句；不得把
“曾经”加强成“一直”，把“经常接触”加强成“共同生活”，把一段经营年限改写成从未离开，
也不得补出失败、成功、创伤、客户反应或他人的一生。

凡输入没有给出的行业物性、人物经历、受众偏好和商业效果，均是创作假设。只允许写入名称带
`_hypothesis` 的字段或每个候选的 `assumptions`，不得写成主体已经拥有的真实资产。
`subject_ownership.fact_refs` 只证明对应事实原句，不能替推断背书。

产品、品牌、组织没有心理欲望；阶段身份不是完整人物。

## 先求语义连续，再求距离

先拆中心概念与修饰语，再形成：表面动作 → 人类动作 → 关系变化 → 社会规则 → 两个合理欲望
不能兼得。每一步必须解释上一项为何能到下一项，不允许凭情绪词跳跃。

三种距离是平行方案：

- `near`：行业对象、专业判断或经营问题仍是内容主体；
- `mid`：行业只提供动作或结构，真正持续讲人的处境、关系和选择；
- `far`：删除职业、产品、场地以及它们的直接相邻角色后，内容命题仍能持续成立。必须实际完成
  `far_deletion_test`，把输入 `surface_terms` 逐项列为已删除；剩余内容主体不得再含这些词。
  主体所有权
  来自输入已给出的观察角度、语言、行动能力或人生经历，而不是来自行业外壳。

若所谓远距离只是从工作对象移到每天顺手遇见的人，或只是把科普改成感悟，它仍没有完成远联。
远联也不是随机换题：必须保留至少两条来源结构与目标结构之间的动作、关系或因果边。

## 收敛

比较三路时只看：是否属于当前主体；观众矛盾是否具体；能否持续产生事件；输入中的生产条件
是否承受；内容之外能否归因。推荐理由只能使用事实原句和已列出的假设，不得在推荐段突然发明
一个更好听的人设。

完成统一路线合同后立即停止，不写人物、剧情、脚本或运营建议。
