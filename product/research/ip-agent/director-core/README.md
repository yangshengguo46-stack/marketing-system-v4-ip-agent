# IP Director Core：离线合同原型

状态：`research_quarantined`

本目录验证一个最小假设：把系统论、本体论、信息论和控制论落实为结构化合同，
并在创作层加入“语义拆解 → 固着基线 → 远距离结构关联 → 营销/生产收敛”，
是否能阻止模型只把第一个行业联想越写越深。

它不是现役 IP Agent、不是已经验证的定位能力，也不改变
[`IP_AGENT_PRODUCT_LEDGER.md`](../../../../docs/IP_AGENT_PRODUCT_LEDGER.md) 中
MF-E1 为当前验证批次、M2-E4 为待转化的状态。

## 权威边界

- 事实权威仍在用户、来源和未来业务本体，不在模型输出；
- 方向只是一份可证伪工作假设，不恢复旧 strategy/differentiation 表；
- 本体与信息规则由校验器检查，创造性必须另做盲审；
- 人物、产品和组织采用不同取材入口；中段共用一个方向作者；
- 公众认知与运营者自己的名称、口号和视觉声明分开；
- 默认 Agent、Gateway、数据库、MCP、Skill 配置均不得 import 或注册本目录。

## 当前通过含义

离线测试通过，只能证明合同能够拒绝已知的本体和信息错误。它不能证明模型会正确填充
合同，也不能证明方向有创意、视频会传播或业务会转化。等 MF-E3 的稳定业务主键和首条
纵切成立后，才允许把本方法接入封存的 placebo/method 盲测仪器。

## 2026-08-04 S4 直连模型试跑

首次 canary 使用阶段角色人物样本，直连 `doubao-seed-evolving-latest-version`，
不经 Gateway、Agent、Skill 或工具。结果为失败，不计入产品能力：

- 本体纠偏和生产路由有效：没有把当前家庭角色当人物本体，也没有强迫露脸或展示家人；
- 信息合同失败：两条 `derived` claim 缺少 provenance；
- 远联层级混淆：运动员复出和手艺复健是结构来源，不是两个独立的目标 IP 方向；
- 系统只建立了“训练→记录→比较”的技能内环，没有建立“内容干预→公众关系变化”的 IP 外环；
- 十二条只是训练指标换名，尚未形成关系、选择、代价和状态转化的事件系统；
- 270.449 秒、20,171 Token 的负担不适合首轮交互，完整合同只可能是未来异步深度编译任务。

下一次只验证“本体→远联来源→目标方向→双环样片”的最小切片，
将事实 provenance 由测试程序预绑定，不让模型重复搬运整份内部合同。

## 2026-08-04 Ark Managed Agent 三模型对照

三模型、三场景、同合同、同环境、零工具的真实对照已经完成。独立盲审中 Evolving
质量最高且三题均为合法 JSON；Turbo 三题均最快，但内容更模板化；Pro 的创意命名较强，
却同时出现事实升级、结构化输出失败和额外模型续跑。研究阶段方向内核默认使用
Evolving，Turbo 只保留为快速对照，Pro 暂不进入后续实验。完整证据见
[`ark-model-comparison-20260804.md`](ark-model-comparison-20260804.md)。

## 2026-08-04 因果桥一句话故事

第一轮能正确拆解中心概念并生成完整动作链，却把商业目标直接变成故事人物目标，最终写成
账号主理人争取流量和咨询的经营故事，判定失败。第二轮不换模型，只分开故事世界与商业
世界：先让虚构人物的关系、欲望、反馈、选择和状态改变独立成立，再单独连接公众归因和
商业目标。它虽然不再含账号、流量、平台或咨询，却把商业对象降格为可被任意纪念物替换
的软植入；替换后因果完全不变，因此第二轮仍判失败。

第三轮新增商业对象出场决策：要么对象不可替代地改变因果，要么从故事世界彻底退出，
禁止可替换植入。本轮固定为退出，以同一输入检验“只保留人的关系因果”是否成立。真实
Evolving canary 的 `story_world` 和 `logline` 已不含商业对象、材质、礼物、纪念物或信物，
仅由人物行动、反馈、代价选择和关系变化完成，故只对 `absent` 单项假设判通过；它仍不是
产品能力。模型耗时 160.659 秒、11195 Token，且故事偏家庭强情节，下一轮必须用跨品类
`absent` 与真实 `causal` 样本排除“全局隐藏产品”和固定剧情两种退化。
