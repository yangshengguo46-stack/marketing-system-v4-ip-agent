> 为什么别的 Agent 也能写定位、脚本和视频，而我们的 Agent 能帮助人物、品牌、产品、

## 结论摘要

### 1. “会做 IP”是能力，“形成差异化”才可能成为壁垒

现有系统已经有很强的下游能力：

- 77 个已激活 Skill（本轮新增唯一上游总控 `design-ip-differentiation`）；
- 35 个电影化 IP Skill；
- 358 部影片、393 位创作者或团队、304 张机制卡的本地电影化研究库；
- 18 个生成媒体工艺与成片工作流 Skill；
- 品牌发布片、产品广告、UGC 广告、视觉风格、角色连续性、视频对标学习等能力；
- 56 个 `personal_ip_*` 原生工具和追加式经营证据链。

这些能力证明系统能研究、策划、写作、导演、生成、剪辑、发布和复盘，却不自动证明它能
做出差异化。没有上游差异命题时，35 个电影化 Skill 只会把同质化内容拍得更复杂、更漂亮。

### 2. 差异化不是一个分数，而是六种不同的能力

本产品必须分开保存：

1. **价值差异**：为什么特定公众要选择、采用、相信或付费；
2. **意义差异**：它如何重新解释一个问题、类别、身份或文化矛盾；
3. **戏剧差异**：为什么它能持续发生只有这个主体才会发生的选择、关系和事件；
4. **识别差异**：公众如何在没有完整名称提示时仍能认出并正确归因；
5. **证据差异**：哪些能力、产品机制、经历、数据、关系和结果不是一句口号；
6. **生成差异**：如何在保持身份的同时连续产生新鲜表达，而不是重复一个爆款模板。

“原创”“醒目”“电影感”“爆款”“差异化”“壁垒”不是同义词。

### 3. 广告、品牌与电影研究共同给出的答案

- 广告创意不只是原创，还要与受众、品牌和问题相关。覆盖 93 个数据集、67 篇论文、
  878 个效应量的元分析发现，创意同时包含 originality 与 appropriateness 时，对广告和
  品牌反应的解释力高于只看原创
  ([Rosengren et al., 2020](https://journals.sagepub.com/doi/10.1177/0022242920929288))。
- 适度打破类别预期可能促进处理与评价，但极端不一致如果不能被理解，反而需要额外的
  “解释桥”
  ([Meyers-Levy & Tybout, 1989](https://academic.oup.com/jcr/article-abstract/16/1/39/1791662))。
- 故事能够让受众进入叙事世界；76 篇已发表和未发表研究、132 个效应量的元分析支持
  narrative transportation 是一种可研究的消费者反应机制，但不是“讲故事就必卖货”
  ([van Laer et al., 2014](https://academic.oup.com/jcr/article-abstract/40/5/797/2907487))。
- 叙事加工可以增强人与品牌的自我连接，但前提是故事的意义能与受众经验发生连接
  ([Escalas, 2004](https://doi.org/10.1207/S15327663JCP1401%262_19))。
- 独特品牌资产必须同时解决“只指向这个主体”和“足够多人已建立该联想”；颜色、角色、
  字体或声音不是设计出来就自动成为资产
  ([Ehrenberg-Bass](https://marketingscience.info/news-and-insights/brands-of-distinction))。
- Ipsos 对 2,000 多条视频创意的行业元分析把品牌自有角色与声音线索同 branded attention
  联系起来，提示“借来的明星/音乐注意力”和“沉淀到自己的识别资产”应分开评估
  ([Ipsos, 2020](https://www.ipsos.com/en/power-you-why-distinctive-brand-assets-are-driving-force-creative-effectiveness))。
- WARC/LIONS 的 Creative Effectiveness Ladder 把一次有影响力的创意、行为变化、短期销售、
  品牌建设、商业增长和三年以上的 enduring icon 分为不同层级；其研究基于 4,863 个效果奖
  参赛及获奖案例，适合做目标分层，不应当作所有市场的因果定律
  ([WARC](https://www.warc.com/en/article/the-effectiveness-code-63d75d4dfc3547f4b8a84f6f4d1bf6e2))。

共同结论不是“只要故事好，到哪都能爆”，而是：

> **真实且有用的差异决定为什么值得选择；戏剧与创意决定为什么愿意看、理解和感受；
> 独特资产决定注意与记忆归谁；持续经营与证据学习决定它是否从一次作品变成资产。**

### 4. 我们真正可建立的壁垒

单独的 Skill 文本、提示词数量、模型调用和电影术语很容易被复制。更难复制的是以下系统
共同工作的结果：

1. 用户专属的事实、产品、能力、关系、事件和证明图；
2. 类别惯例、竞争领地、反对标和远距机制样本构成的对比语料；
3. 35 个电影化 Skill 编译出的主体专属叙事与视听语法；
4. 版本化的差异命题、创作圣经、独特资产和不可变试验；
5. 真实发布、归因、意义、偏好、采用、转化和延展观察；
6. 跨主体匿名聚合后形成的“何种差异在何种条件下有效”的机制学习；
7. 随时间积累的识别资产知名度、关系历史和内容世界。

因此目标产品不应宣传“AI 帮你想一个独特点子”，而应成为：

> **一个把主体真实材料编译成差异化战略、叙事系统、识别资产和可校准经营证据的
> Differentiated IP Operating System。**

## 一、必须先拆开的六个概念

| 概念 | 回答的问题 | 典型误判 |
| --- | --- | --- |
| 战略差异 `differentiation` | 为什么选择、相信、采用、付费或跟随它，而不是替代方案？ | 换一个口号就叫定位 |
| 独特识别 `distinctiveness` | 看到、听到或体验到什么时，公众能认出并正确归因给它？ | 用一种颜色就叫品牌资产 |
| 创意 `creativity` | 表达是否兼具原创性和适切性，值得处理又服务目标？ | 越怪、越反常就是越有创意 |
| 显著/注意 `salience/attention` | 它能否在特定时刻进入注意与记忆提取？ | 抢到注意就等于形成偏好 |
| 叙事身份 `narrative identity` | 它通过什么角色、关系、选择和世界持续表达“它是谁”？ | 拍一个剧情片就有故事资产 |
| 防御性 `defensibility` | 竞争者能否不改变自身能力、不撒谎、低成本快速复制？ | 画面高级、设备昂贵就是壁垒 |

### 1.1 差异不等于醒目

一个统一使用荧光绿色、怪异表情和高分贝配乐的账号可能很醒目，但如果公众不知道它解决
什么、代表什么、为何可信，它只有感知差异，没有价值差异。

### 1.2 醒目不等于正确归因

广告或视频可能让人记住笑点、明星、音乐、导演风格，却记不住主体。Ipsos 将注意、创造性、
品牌线索和媒介共同放进“memorable attention”，并强调品牌识别是长期记忆的一部分
([Ipsos, 2026](https://www.ipsos.com/en/noise-noteworthy))。因此本产品不能把“看过”自动写成
“资产增长”。

### 1.3 原创不等于有用

广告创意元分析区分 originality 与 appropriateness。原创主要提高情感和处理机会，适切性
把创意与受众问题和品牌策略连接。只优化“没见过”，会得到怪异但无关的作品；只优化
“有用”，又容易得到正确但可替换的说明书。

### 1.4 电影感不等于戏剧差异

浅景深、胶片色、慢动作、对称构图、强配乐和长镜头都是表面语汇。戏剧差异来自：

- 谁在欲望与义务之间做什么选择；
- 哪种关系会反复制造只能发生在这个主体身上的冲突；
- 什么信息只从这个视点被看到；
- 哪种代价与变化证明主体的价值；
- 这个世界有哪些稳定规则和可变化状态。

换掉主体后剧本仍完全成立，说明它是通用格式，不是主体的戏剧差异。

### 1.5 爆款不等于差异化资产

一次传播可能由题材、时机、分发、争议、热点、平台样本、外部账号带动。只有当它同时：

- 正确归因给目标主体；
- 加深预期意义；
- 产生目标行为或关系；
- 能在后续作品中变化复现；
- 不依赖侵权或不可控资源；

才可能贡献于 IP 资产。一个爆款不能永久固化为规则。

### 1.6 差异化不等于壁垒

差异可以很快被复制。真正的壁垒需要差异与专有事实、组织能力、产品机制、关系、数据、
识别资产知名度和学习速度连接。表面创意被抄，不等于底层系统被抄；若对方能七天内完整
复制且不需要撒谎或改变经营方式，则它最多是临时创意优势。

## 二、差异化 IP 的第一性原理

### 2.1 IP 为什么需要差异

IP 是一种影响力资产。影响发生在公众面对注意、理解、记忆、信任和选择成本时。若一个
主体与替代方案没有可感知、可解释或可归因的差别：

1. 公众没有理由分配额外处理资源；
2. 即使接触，也难形成独立记忆节点；
3. 即使产生需求，也可能把选择交给价格、便利或平台排序；
4. 即使内容成功，价值也可能归到题材、明星、模板或平台；
5. 经营者只能持续追逐热点，不能让历史投入复利。

但公众选择一个主体，不要求它在所有维度“世界唯一”。品牌定位研究同时要求 points of
parity 与 points of difference：先满足进入类别和被信任的最低条件，再建立选择理由
([Keller, Sternthal & Tybout](https://hbr.org/2002/09/three-questions-you-need-to-ask-about-your-brand))。

因此差异化不是一味反常，而是：

> **在不破坏必要可信度和类别理解的前提下，让目标公众感到“这件事由它来做更合理、
> 更值得、更能代表我，且我认得出来”。**

### 2.2 七类差异来源

#### A. 事实差异

来自不能随意捏造的材料：

- 人物经历、训练、能力、代价和关系；
- 品牌来源、组织选择、历史行为和声誉；
- 产品机制、交互、结构、工艺、数据和使用结果；
- 角色世界、原始设定和版权资产；
- 方法的步骤、边界、反例和迁移证据；
- 社区的成员、规范、仪式和集体行动。

这是后续所有差异的真实性底座。

#### B. 选择差异

差异经常不是“多一个优点”，而是做出别人不愿或不能做的取舍：

- 服务谁，也明确暂不服务谁；
- 优先什么，也承认牺牲什么；
- 坚持何种做法，也拒绝什么捷径；
- 用何种证据说话，也不借什么虚假权威；
- 接受什么代价，证明承诺不是文案。

没有牺牲的“既要、又要、全都要”通常是同质化愿望清单。

#### C. 价值差异

价值差异连接到真实情境中的进步、问题和采用阻力。Jobs to Be Done 被 Christensen
Institute 定义为理解人们为什么改变行为的研究方法
([Christensen Institute](https://www.christenseninstitute.org/theory/))。本产品借用的是
“情境中的进步”这一研究方向，不把它当万能模板：

- 何时产生需求；
- 公众试图完成什么功能、情绪或社会进步；
- 目前用什么替代方案；
- 什么焦虑、习惯、成本和权力关系阻止改变；
- 什么证明足以触发一个更小的下一步。

#### D. 意义差异

同样的功能可以被放进不同的解释框架。意义差异回答：

- 这个主体认为问题真正是什么；
- 它反对哪种默认叙述；
- 它如何解释一个群体长期感到却未被准确命名的矛盾；
- 它希望公众成为怎样的人或建立怎样的关系。

Douglas Holt 的文化战略工作强调从社会文化变化和既有类别惯例之间寻找机会，而不只是
做更好的“捕鼠器”
([Holt, 2020](https://hbr.org/2020/09/cultural-innovation))。对本产品而言，文化差异必须
同时满足：

- 有可观察的文化矛盾，不是凭空制造对立；
- 与主体的产品、能力或行为真相连接；
- 不挪用弱势群体经验，不靠仇恨和虚假争议；
- 能被具体行动和体验兑现。

#### E. 戏剧差异

这是 35 个电影化 Skill 最能贡献的部分。戏剧差异不是“说什么观点”，而是把意义变成：

- 一个不断追求目标的主体；
- 一个合理且稳定的反欲望或结构性阻力；
- 一组互相依赖又不断冲突的关系；
- 一个让选择产生可见代价的世界；
- 一种观众长期回来时能获得的类型和情绪承诺；
- 一套能连续生成事件而非连续复述口号的规则。

#### F. 编码差异

编码让主体在低注意、静音、小屏、跨平台和重复接触中仍可被识别，包括：

- 语言：命名、句式、口头结构、问题框架；
- 视觉：形状、构图、颜色关系、材质、光线、镜头距离；
- 声音：声音标记、节奏、音色关系、固定声源；
- 角色：轮廓、动作词汇、关系位置、道具；
- 空间与仪式：固定场所、出场方式、产品使用动作、共同体仪式；
- 行为：交付方式、服务动作、产品交互和对问题的处理顺序。

编码差异只有在受众确实把它与主体建立联想后，才成为资产；在此之前只是候选。

#### G. 学习差异

长期经营中，单个创意会被复制，模型能力会普及。更稳固的差异来自：

- 更早知道哪些公众、情境和问题值得解决；
- 更准确知道什么机制在什么条件下有效；
- 更快淘汰错误判断；
- 保留失败证据而不事后改口；
- 把跨周期观察编译成新的策略和创作版本。

这也是 Agent 最适合形成产品壁垒的一层。

### 2.3 一个有用但非科学定律的乘法启发式

可以用下式检查明显短板，但不能把它实现成一个伪精确总分：

```text
差异化 IP 壁垒
= 有价值的相对差异
× 专有事实与证明
× 可正确归因的编码
× 可持续的叙事生成
× 真实体验的一致兑现
× 证据学习与版本控制
```

任一项接近零时：

- 原创但无关：怪；
- 有用但可替换：商品；
- 醒目但无法归因：免费娱乐；
- 意义鲜明但无证明：脆弱口号；
- 一个格式能爆但无法续写：一次性作品；
- 视觉独特但产品体验相反：声誉负债；
- 有好方法但不学习结果：静态模板。

## 三、如何理解“差异化”与“独特识别”的学术争论

### 3.1 Ehrenberg-Bass 的挑战

Romaniuk、Sharp 与 Ehrenberg 在跨类别、跨两国数据中观察到，许多被购买的品牌并没有
很高的感知差异，因此质疑“必须拥有强烈感知差异才能竞争”，主张把容易识别的独特联想
放到品牌战略中心
([论文摘要](https://www.sciencedirect.com/science/article/abs/pii/S1441358207700423))。

这个证据对本项目的重要提醒是：

- 不要强迫每个主体发明“世界唯一”的功能；
- 不要把用户说不出的宏大差异当失败；
- 类别进入、可获得性、识别和稳定积累可能比一句绝对 USP 更重要；
- 一项视觉或声音线索的价值要测 fame 与 uniqueness，而不是设计师自评。

### 3.2 Kantar 等研究的反方向证据

Kantar 的 Meaningful, Different and Salient 框架使用其商业数据库主张，
meaningful difference 与定价能力和未来增长相关，而即时选择仍同时受 meaningfulness 与
salience 影响
([Kantar](https://www.kantar.com/Inspiration/Brands/Dancing-to-the-rhythm-of-brand-differentiation))。

这些数字来自专有模型与商业数据，不能当所有类别的普遍因果定律；但它提醒本项目：

- 只让公众认出一个主体，不等于给出偏好或溢价理由；
- 新进入者、挑战者、高参与产品、方法型 IP 和专业服务，通常更需要清楚的可信差异；
- 产品、组织和体验的真实差异可能先出现，感知差异随后累积；
- “差异不重要”不能成为停止创新和证据建设的借口。

### 3.3 本产品不站伪二选一

两套研究测量的问题不同，可以被拆成两个正交问题：

| 产品问题 | 需要的能力 |
| --- | --- |
| 为什么选我、信我、付费、采用、跟随？ | 价值、意义、证明和体验差异 |
| 公众如何在接触和选择时认出这是我？ | 独特识别、正确归因和心智可提取 |

目标系统必须同时建：

1. `reason_to_choose`；
2. `reason_to_recognize`。

不应生成一个“差异化 87 分”把二者再次混在一起。

## 四、电影、编剧、导演能力怎样真正贡献差异化

### 4.1 35 个电影化 Skill 不是 35 个滤镜

现有正式矩阵是：

- 1 个编排总控；
- 4 个操作系统；
- 9 个基础模块；
- 11 个工种实验室；
- 10 个类型编剧室。

它们的共同价值不是模仿 35 种风格，而是把抽象战略翻译成观众能够看见、听见、期待和
追更的机制。

### 4.2 从战略差异到屏幕差异的映射

| 电影化能力 | 对差异化的贡献 | 不能代替什么 |
| --- | --- | --- |
| `ingest-ip-evidence` | 建立真实人物、事件、关系、物件和边界材料 | 市场差异结论 |
| `query-cinematic-library` | 从影片、创作者和机制卡取互补证据样本 | 直接仿写某导演 |
| `distill-screen-methods` | 抽取视点、关系、场面、时间、声音等可迁移机制 | 品牌和产品事实 |
| `engineer-desire-behavior` | 把价值观变成目标、阻力、策略、代价和选择 | 一句定位 |
| `develop-theme-premise` | 把真实矛盾变成主题问题、正反题和可持续前提 | 市场需求证明 |
| `design-character-relations` | 让人物通过不同欲望、盲点、能力和关系被辨认 | 静态人设标签 |
| `route-ip-genre-engine` | 建立观众重复期待的类型合同，并允许有意义的类型反转 | 题材标签 |
| `shape-ip-emotion` | 建立稳定情绪承诺及其变奏 | 单纯煽情 |
| `engineer-plot-information` | 通过信息差、揭示顺序和视点形成独特认知体验 | 假悬念 |
| `design-ip-series-bible` | 把主体变成可持续事件、关系、世界与仪式生成器 | 发布日历 |
| `write-ip-episode` 等 | 把上游差异编译成具体单集、场景、对白和行动 | 上游差异命题 |
| 导演、调度、摄影 | 让权力、距离、选择和关系在无对白时仍可见 | 漂亮镜头堆积 |
| 光色、世界、美术 | 把社会位置、记忆、材质和规则编成稳定视觉语法 | 只选一个 LUT |
| 声音设计 | 建立主观听觉、画外空间、声音母题和可识别线索 | 随机热门 BGM |
| 表演与剪辑 | 让主体行为节奏、反应、停顿和变化形成可辨风格 | 假表演与节奏刺激 |
| `audit-ip-continuity` | 审查主体承诺、人物状态和长期世界是否漂移 | 生成资产像素一致性 |

### 4.3 本地研究库已经证明“机制迁移”方向是对的

本轮对本地电影化研究库做了差异、识别、仪式、视点和品牌查询，返回的机制包括：

- “电影能力迁移而非降维复制”；
- “显眼差异先争取识别”；
- 主观孤独与环境表面的内外差异；
- 视点控制和观众信息位置；
- 日常仪式作为情绪入口；
- 色彩分章、仪式空间和跨部门 look；
- 个人品牌作为从当前处境到可被识别价值的成为过程。

这些是研究线索，不是可以直接套用的公式。它们共同说明：

> 影视库应提供“差异机制”，不能提供“帮用户变成某导演、某账号”的模仿目标。

### 4.4 电影能力最有价值的五种壁垒贡献

#### 贡献一：把口号变成有代价的选择

“真诚”“专业”“长期主义”人人能说。只有主体在压力下舍弃什么、保护什么、如何行动，
观众才得到可观察证明。欲望—行为、场景和对白 Skill 可以让价值差异从形容词变成行为。

#### 贡献二：把信息差异变成体验差异

同一事实从谁的视点、何时揭示、观众比人物多知道什么，会产生完全不同的体验。Hitchcock
式“观众信息位置”等本地机制卡的价值，在于帮助系统设计可迁移的信息关系，而非复制镜头。

#### 贡献三：把人物标签变成关系发动机

孤立的“毒舌老板”“温柔妈妈”“硬核工程师”很快枯竭。真正可持续的是：

- 主体与搭档共同想要什么；
- 他们各自害怕什么；
- 为什么互相依赖；
- 哪种触发器会让旧矛盾在新事件中复发；
- 每次关系变化如何留下不可逆状态。

#### 贡献四：把视觉识别变成世界与仪式

颜色和字体容易复制。空间所有权、产品使用动作、人物出场方式、固定道具、声音母题和关系
仪式组合成“世界语法”后，识别更丰富，也更能随事件变化。

#### 贡献五：让一致性与新鲜感同时成立

系列圣经、类型、情绪、世界、角色和连续性共同回答：

- 哪些必须不变，才能仍然是这个 IP；
- 哪些必须变化，才能不让观众疲劳；
- 什么变化可以累积，什么每集复位；
- 如何连续 12 集、一个季度、三年仍有事件。

这是电影与编剧工具相比一次性文案生成器的核心优势。

## 五、广告和营销能力怎样防止“电影化自嗨”

### 5.1 广告提供的是“任务约束”

电影能力能制造体验，但 IP 经营还要回答：

- 公众是谁，处在什么情境；
- 需要改变什么认知、关系或行为；
- 主体能兑现什么承诺；
- 什么证据支持；
- 哪个资产应该获得归因；
- 一次内容在 reach、trust、proof、conversion 中承担什么角色；
- 成功和失败用什么证据判断。

### 5.2 现有广告 Skill 已经做对的部分

#### `product-ad-production`

现有能力已经要求：

- 先写受众情境、job、产品真相、命题、证据与异议；
- 先建 claim ledger，再建视觉系统；
- 多个概念必须在机制上不同，不是只换调色；
- 把产品识别、机制、证明、CTA 和目标页面一致性编进成片；
- 变体要对应一个可学习假设；
- 不能把未测量的颜色或轮廓当成品牌名替代。

这是差异化引擎的“价值—证明—实验”基础。

#### `brand-launch-film-production`

现有能力已经把发布片定义为 business-critical asset，要求：

- 谁需要改变想法或行为；
- 单一发布承诺；
- 支持承诺的产品、人和市场证明；
- 品牌声音、视觉、合规和多平台交付；
- manifesto、demo-as-drama、category contrast 等不同故事路线。

问题是它目前消费一个已有定位 brief，并不负责证明上游差异命题成立。

#### `ugc-ad-production`

它能把原生感、第一人称、产品接近、生活细节和直接证明编成广告，同时防止伪造用户经验、
虚假评论和未披露商业关系。它适合测试“可信表达形式”，不适合代替品牌或产品差异。

#### `visual-style-direction`

它已经区分参考观察、解释、可迁移机制、身份细节排除，要求：

- 一句话视觉命题；
- invariants、controlled variables、anti-patterns；
- originality pass；
- 多参考源防止设计固着；
- 跨图像、视频、比例和生产者的便携规则。

它是差异化引擎的视觉编译器，不是差异战略制定者。

#### `reference-media-analysis` 与 `video-pattern-learning`

二者共同建立了正确边界：

- 学习功能、结构、节奏、镜头、声音和生产语法；
- 不复制文案、角色、构图、旋律、声音身份和 trade dress；
- 单个爆款只能生成 experimental pattern；
- portable pattern 需要至少三个独立发布和证据晋升。

问题是当前对标主要回答“它为什么有效”，还没强制回答“这个类别已经被说烂、拍烂了什么，
我们明确不进入什么领地”。

### 5.3 广告效果研究对系统的三条硬约束

#### 约束一：原创必须与适切相乘

Rosengren 等人的元分析要求系统在候选创意上分别保存：

- originality；
- audience/problem appropriateness；
- brand/subject appropriateness；
- execution quality。

不能只问“新不新”。

#### 约束二：记住广告不等于记住主体

独特资产和品牌归因必须进入每条试验。若笑点、角色、音乐或剧情获得注意，但主体归因下降，
这不是完整成功。

#### 约束三：一次创意效果不等于长期资产

IPA 对近 600 个 1996–2018 效果案例的分析将短期主义与创意效果下降联系起来
([IPA, The Crisis in Creative Effectiveness](https://ipa.co.uk/knowledge/publications-reports/the-crisis-in-creative-effectiveness/))。
WARC 的效果阶梯进一步把一次参与、销售、品牌建设和三年以上持久图标区分。两套都来自
效果奖案例，存在样本选择限制；但足以支持一个产品原则：

> 不用一个短期播放或一次转化，替代对长期识别、意义、偏好和商业结果的观察。

## 六、当前系统距离“差异化 IP 壁垒”还缺什么

### G1：没有版本化的差异命题契约

当前策略能写 `difference`，但没有强制区分：

- 价值差异；
- 意义差异；
- 戏剧差异；
- 识别资产；
- 证据与可复制性；
- 不变项与可变项；
- 假设和证伪条件。

一个自由文本 `difference` 无法稳定向 35 个电影化 Skill、广告生产和观察系统传递。

### G2：对标缺少“竞争对比集”

当前策略要求至少三个真实对标，视频学习也能抽取生产语法。但只看优秀样本会造成趋同。
差异化研究至少需要五类对比：

1. 类别基线和必要同类点；
2. 直接竞争者已经占据的价值与表达领地；
3. 当前替代方案和“不做任何改变”的状态；
4. 远距行业、电影和创作者的可迁移机制；
5. 反对标：我们明确拒绝的口号、结构、审美、行为和风险。

### G3：没有“类别陈词滥调账本”

系统可以分析一个对标，却没有统一保存：

- 高重复开头；
- 泛化人设；
- 常见观点与空洞价值词；
- 默认镜头、灯光、字幕和 BGM；
- 被过度使用的剧情反转；
- 同类品牌颜色、角色和声音；
- 已经失去区分度的“行业高级感”。

没有这张账本，Agent 很容易输出统计上最常见、语言上最流畅的同质答案。

### G4：专有事实没有被编译成“可证明差异”

现有系统能登记证据，但尚缺：

- 哪个事实支持哪个差异命题；
- 它对公众是否相关；
- 竞争者是否也能诚实声称；
- 是否能被画面、行为、产品或第三方证据展示；
- 证据何时失效；
- 哪些事实只能内部使用。

### G5：没有“战略牺牲”

多数定位模板只生成积极形容词，没有要求：

- 我们不服务什么；
- 不承诺什么；
- 不采用什么增长捷径；
- 愿意接受什么成本；
- 什么结果出现就承认方向错误。

缺少牺牲，候选方向会在语言上不同、实质上相同。

### G6：电影化能力没有接收统一差异输入

现有 35 个 Skill 共享欲望账本、主题、类型、情绪、世界、视觉语法等概念，但没有一个
后端 `ip-differentiation-thesis` 作为正式上游。结果可能出现：

- 主题很深，但与产品或公众问题无关；
- 类型很新，但主体没有资源持续实现；
- 视觉很独特，但与竞争者混淆；
- 角色很讨喜，但注意力没有归因给目标品牌；
- 剧情有张力，但证明的是错误承诺。

### G7：独特资产只被设计，没有被测量

系统缺少：

- 无提示与有提示识别；
- 主体混淆矩阵；
- 资产 fame/uniqueness；
- 视觉、语言、声音、角色和仪式的单项及组合归因；
- 正确意义和错误意义；
- 跨平台、跨比例、静音和短时暴露表现。

### G8：长期创作真相还在 Skill 输出和聊天

电影化总控定义了长期共享状态，但后端没有版本化 creative bible 和 expression system。
没有这一层，就无法：

- 比较两个差异版本；
- 知道一条内容用了哪个采用版本；
- 审计什么保持不变、什么发生变化；
- 将发布结果归因到某个差异或表达假设；
- 安全回滚。

### G9：学习闭环还没有“差异层结果”

当前发布前预测和发布后复盘主要面向内容和平台表现。差异化还需要观察：

- 是否被描述为不同；
- 差异是否相关、可信；
- 是否增强选择、偏好、采用或溢价；
- 是否正确归因；
- 是否能延展到新内容、产品或场景；
- 竞争者复制后，公众是否仍认原主体。

### G10：现有产品主体仍偏个人创作者

`ip-strategy-director` 仍以 personal-IP、person and business discovery 为主。品牌、产品、
角色、方法和组织需要不同的差异原料与证明。这个缺口已在上一份研究中详细说明，本轮只加
一个约束：

> 差异化引擎的上游主体必须来自通用 IP 实体图，不能默认用“个人故事”包装所有品牌和产品。

## 七、目标系统：Differentiated IP Engine

### 7.1 不是再增加 35 个 Skill

建议新增一个顶层决策能力，并把状态存到后端契约：

- 内部能力名可暂定 `design-ip-differentiation`；
- 它不直接写最终脚本、镜头或生成提示；
- 它编译一个版本化 `ip-differentiation-thesis-v1`；
- 35 个电影化 Skill、广告 Skill 和媒体生产 Skill 只消费已采用的命题；
- 它与通用 `ip-strategy-director` 协作，不替代实体组合、商业模式和经营目标。

对标对比、类别陈词滥调和反对标应作为这一能力的研究模式，不必各新增一个 Skill。

### 7.2 核心数据流

```text

    ↓

    ↓

    ↓

    ↓
电影化创作圣经 / 表达系统 / 广告任务 / 试验组合
    ↓
脚本、试拍、生成、拍摄、发布
    ↓
平台表现 + 正确归因 + 意义 + 信任 + 选择 + 商业/采用结果
    ↓
不可变复盘、证据晋升、版本修订
```

### 7.4 为什么必须版本化

差异化不是一次定位会。一个版本可能：

- 价值正确但表达无法归因；
- 视觉醒目但公众理解错误；
- 主角有魅力但品牌被遮蔽；
- 产品证明强但情绪承诺不成立；
- 某平台表现差但跨平台资产指标良好；
- 一个季度有效，后来被竞争者复制或类别改变。

只有不可变版本、内容绑定和结果绑定，系统才能知道该改哪一层。

## 八、差异化候选如何生成

### 8.1 先建五个对比集合

#### 集合一：类别最低可信条件

列出公众进入选择时必须看到的能力、规格、伦理、价格、服务或专业证明。差异不能以破坏
基本可信为代价。

#### 集合二：竞争者已经占据的领地

不是只抄账号粉丝量和爆款，而要记录：

- 它承诺什么；
- 用什么证据；
- 代表何种身份或意义；
- 主角、关系、世界和仪式是什么；
- 哪些视觉、语言、声音已与它强关联；
- 哪些地方只是行业通用。

#### 集合三：替代方案与不行动

产品和内容的真实竞争者经常不是同类账号，而是：

- 自己解决；
- 继续忍受；
- 购买低价替代；
- 向熟人求助；
- 不相信任何创作者或品牌；
- 把时间用在别的内容上。

#### 集合四：远距机制样本

从电影、纪录片、喜剧、悬疑、品牌角色、产品演示、空间设计、声音和仪式中选 3–6 个
功能互补的样本。只抽取机制，不拼贴身份细节。

#### 集合五：反对标

明确写出：

- 不能成为哪种同质账号、品牌或产品；
- 哪些观点虽有流量但违背主体；
- 哪些美学已经与竞争者绑定；
- 哪些手法依赖虚假、侵权、羞辱或高不可持续成本；
- 哪些模板会让主体可被替换。

### 8.2 生成候选的七个角度

每个候选不必七项全新，但必须至少有一项真实战略差异，并由其他项协同放大：

| 角度 | 候选问题 |
| --- | --- |
| 真相 | 我们拥有或经历了什么别人不能诚实照抄？ |
| 取舍 | 我们愿意承担什么代价，证明不是口号？ |
| 价值 | 在什么情境里，我们让公众获得不同的进步？ |
| 意义 | 我们如何重新命名问题或解决文化矛盾？ |
| 戏剧 | 什么人物、关系和规则能持续制造独有事件？ |
| 编码 | 什么语言、视觉、声音、动作和仪式能归因给我们？ |
| 学习 | 什么假设可以尽快被真实行为和资产观察证伪？ |

### 8.3 每个候选必须回答的十个问题

1. 它相对于谁不同？
2. 不同发生在哪个公众情境？
3. 为什么这种不同有价值？
4. 哪个事实或产品机制支持？
5. 什么出现会证明它是错的？
6. 它需要什么战略牺牲？
7. 竞争者复制时必须改变什么或撒什么谎？
8. 它如何生成 12 个不同事件而非重复 12 次口号？
9. 什么线索让公众认出并归因？
10. 三个月、三年和延展到新产品时，哪些保持不变？

## 九、把 35 个电影化 Skill 编成“差异机制格”

### 9.1 每次不调用全部能力

差异化总控应根据命题选择 4–8 个必要机制，不做全家桶。一个候选至少经过：

1. 一个真实事实/证明机制；
2. 一个欲望—选择机制；
3. 一个关系、视点、信息或类型机制；
4. 一个视觉、声音、空间、表演或剪辑编码机制；
5. 一个连续性与事件生成机制。

### 9.2 六类 IP 的典型路由

| 主要载体 | 优先差异原料 | 常用电影化机制 | 主要风险 |
| --- | --- | --- | --- |
| 人物 | 经历、能力、选择、关系、代价 | 欲望行为、主题、关系、表演、纪录、长期弧 | 把人设口号当真实人格 |
| 品牌 | 来源、承诺、组织行为、文化意义 | 世界、仪式、角色、视觉声音母题、类型承诺 | 电影好看但品牌缺席 |
| 产品/服务 | 机制、使用情境、证明、采用阻力 | demo-as-drama、动作因果、物件、空间、使用仪式 | 用剧情遮住产品 |
| 角色/故事世界 | 角色轮廓、欲望、关系、规则、版权 | 角色、类型、世界、情绪、信息、连续性 | 角色讨喜但无法服务主体 |
| 方法/系统 | 问题框架、步骤、边界、结果 | 侦探式推理、任务纪录、反例、信息揭示 | 包装成玄学权威 |
| 组织/社区 | 使命、规范、成员、共同体仪式 | 群像、关系网络、空间、仪式、纪录 | 用创始人代替组织 |

### 9.3 机制组合不等于风格拼盘

错误做法：

```text
王家卫色彩 + 诺兰结构 + 周星驰喜剧 + 苹果广告 = 差异化
```

正确做法：

```text
主体事实：一个维修团队公开保留每次误判与返工
价值差异：不卖“永不出错”，卖可追溯、能纠错
戏剧机制：每集从一个错误线索进入，团队关系对诊断产生冲突
信息机制：观众先看到症状，后获得被忽略证据
视觉编码：固定工作台、磨损物件、分层证据墙
声音编码：设备原声先于解释
长期承诺：错误如何被发现、承担并修复
证明：真实工单、客户授权、前后状态和失败边界
```

这套组合即使借鉴悬疑的信息分配，也不会变成某部电影的仿制品。

## 十、从第一次对话到长期经营的工作流

### 阶段 0：识别用户当前要建立的 IP 组合

新用户第一次使用时，不扫描空驾驶舱。先回应其当前目标，并在自然对话中逐步识别：

- 主要主体是人物、品牌、产品、角色、方法还是组织；
- 谁拥有、体现、证明、分发和延展它；
- 这次要影响谁、改变什么；
- 用户已经拥有何种事实、产品、内容和证据。

只问会改变战略的下一项，不展示内部问卷和评分表。

### 阶段 1：建立专有事实与权利边界

收集：

- 真实经历、能力、产品和客户材料；
- 可公开、可匿名、只内部和禁止使用的边界；
- 现有名称、视觉、声音、产品形态和内容资产；
- 用户自我判断与可观察证据的分离；
- 当前产能、预算和表达限制。

输出不是“建模完成”，而是“目前可证实的事实、未知和待验证假设”。

### 阶段 2：构建竞争对比场

若用户有对标：

- 先走 benchmark intake router；
- 分离客观描述、生产语法、影视机制、知识方法和权利风险；
- 不把一个爆款当普遍规律；
- 同时补直接竞争者、类别陈词滥调和反对标。

若用户没有对标：

- 按目标公众、类别、表达任务和资源匹配；
- 至少包含直接同类、远距机制样本和反对标；
- 不只给“粉丝最多的三个账号”。

### 阶段 3：生成 2–3 个实质不同的差异候选

候选应在价值、意义、证明、戏剧发动机或经营取舍上不同，不能只是：

- 一个叫专业型；
- 一个叫温暖型；
- 一个叫幽默型。

每个候选必须带：

- reason to choose；
- reason to believe；
- reason to recognize；
- strategic sacrifice；
- 12 事件压力测试；
- 七日复制测试；
- 生产成本和失败条件。

### 阶段 4：用户选择战略方向

Agent 给出推荐与取舍，用户选择或修订。选择后才把候选编译成采用版本。未经外部观察的
版本只能称：

- 当前判断；
- 候选方向；
- 试验方向；
- 暂定采用版本。

不能说“差异化定位已经验证”。

### 阶段 5：编译电影化创作圣经与表达系统

根据载体和命题选择必要电影化能力，生成：

- 主题问题与不能兼得的价值；
- 欲望—行为与选择；
- 人物/产品/角色关系引擎；
- 类型和情绪承诺；
- 视点与信息分配；
- 世界、空间、物件和仪式；
- 视觉、声音、表演和剪辑语法；
- invariants、controlled variables 和 anti-patterns；
- 12 个事件生成器和季度演化。

结果写入版本化 `ip-creative-bible-v1` 与 `ip-expression-system-v1`。

### 阶段 6：设计第一组试验，而不是孤立的一条视频

建议首轮包含 3–6 个用途不同的作品：

- 发现/注意；
- 主体识别；
- 价值理解；
- 信任/证明；
- 选择/采用/转化；
- 必要时的延展测试。

同一作品可以有多种效果，但每个试验只设一个首要判断，避免结果出来后任意解释。

### 阶段 7：试拍和表达载体判断

真人是主要表达载体时，才做 A/B 试拍并观察：

- 是否能执行具体动作和意图；
- 镜头恐惧是否可训练；
- 语言、声音和身体是否支持命题；
- 是否需要访谈、纪录、搭档、产品主角、无真人、混合或数字人；
- 每种方案的真实感、产能、权利和成本。

表现力评估只决定表达载体，不判断用户的人格价值。

### 阶段 8：盲预测、发布、资产观察与商业观察

发布前保存：

- 差异命题版本；
- 创作圣经与表达版本；
- 内容角色；
- 主要机制假设；
- 正确归因、意义、行为和平台信号预测；
- 失败条件与观察窗口。

发布后分开观察：

- 平台分发与观看；
- 主体识别与正确归因；
- 意义复述和差异感知；
- 信任、偏好、再次选择；
- 询问、试用、购买、采用、留存、推荐；
- 生产成本与持续性。

### 阶段 9：修订最早失败的层

| 观察 | 优先修订 |
| --- | --- |
| 无人停留，但看到者很认可 | 创意接入、开头、媒介与分发 |
| 看完但不知道是谁 | 独特编码和主体归因 |
| 认得主体但说不出代表什么 | 意义与价值命题 |
| 理解但不信 | 证明、产品真相、行为兑现 |
| 信任但不行动 | 情境、采用阻力、offer、CTA 或产品体验 |
| 一条有效、后续重复疲劳 | 事件生成、关系、类型变奏 |
| 平台差但资产指标好 | 平台适配，不轻易推翻核心差异 |
| 流量高但错误意义增加 | 立即处理声誉与意义漂移 |

## 十一、差异化的发布前压力测试

### 11.1 交换测试

把主体名替换成直接竞争者，脚本、视觉和承诺是否仍完全成立？

- 是：高度同质；
- 部分成立：标出哪些是类别基线；
- 只有本主体成立：追溯真实证据。

### 11.2 去标测试

去掉 logo、名称和显式自我介绍后，目标公众能否：

- 判断类别；
- 认出主体；
- 不与竞争者混淆；
- 说出依据。

新资产早期不能要求高识别，但必须保存基线和建立速度。

### 11.3 证明测试

每个强承诺是否能映射到：

- 产品演示；
- 主体行为；
- 可审计数据；
- 客户或第三方证据；
- 清楚边界和反例。

没有证明时降低承诺，不用电影语言掩盖。

### 11.4 适切测试

原创元素是否同时连接：

- 目标公众；
- 真实情境；
- 主体战略；
- 作品任务。

若只能回答“很酷、很少见”，则是原创候选，不是完整创意。

### 11.5 可理解的不一致测试

类别预期被打破到什么程度？Meyers-Levy 与 Tybout 的三项新产品实验支持适度 schema
incongruity 可能促进处理与评价；极端不一致则可能难以解释。对 IP 试验应检查：

- 哪个预期被打破；
- 公众为什么能理解这种打破；
- 是否存在一个事实、角色、产品或空间“解释桥”；
- 解释后是否仍保留惊喜。

### 11.6 十二集测试

不用热点，能否生成 12 个：

- 事件不同；
- 选择不同；
- 关系状态变化；
- 证明来源不同；
- 仍然属于同一 IP 的内容。

若只能复述同一句观点，命题不是生成系统。

### 11.7 七日复制测试

竞争者能否在七天内复制：

- 口号；
- 剪辑；
- 视觉；
- 角色；
- 产品体验；
- 证据；
- 关系和历史；
- 受众联想。

表面被复制正常。真正的判断是对方要完整复制时，是否必须：

- 改变产品或组织；
- 获得新的权利和关系；
- 积累相同证据；
- 承担相同取舍；
- 经过长期一致曝光。

### 11.8 延展测试

当主体进入新产品、新题材、新平台或新角色时：

- 什么资产继续识别它；
- 什么意义仍被接受；
- 哪些不变项会限制延展；
- 是否发生母品牌、人物、产品或角色的归因冲突。

## 十二、差异化的发布后观测

### 12.1 不做单一“差异化分”

至少建立以下带来源、观察时间、样本、覆盖和不确定性的维度：

| 维度 | 示例观测 |
| --- | --- |
| 发现 | 目标公众是否停留、进入、搜索或被触达 |
| 正确归因 | 无提示/有提示主体识别、混淆对象 |
| 意义 | 受众用什么词复述它代表什么，是否与命题一致 |
| 相对差异 | 相比直接替代，认为哪里不同 |
| 相关性 | 不同是否连接真实需求或身份 |
| 可信度 | 承诺是否被相信，依据是什么 |
| 关系 | 信任、亲近、期待、身份认同、共同体参与 |
| 选择 | 偏好、询问、试用、采用、购买、推荐、复购 |
| 溢价/牺牲 | 是否愿意付出更多价格、时间、切换或公开支持 |
| 生成性 | 变体是否仍被认出、重复是否疲劳、事件是否枯竭 |
| 延展 | 新产品、格式、角色和平台是否仍被接受 |
| 防御性 | 竞争模仿后，原主体是否保留归因和偏好 |

### 12.2 平台指标只是证据的一部分

播放、完播、点赞、评论、转发和关注帮助诊断分发、消费与社交反应，却不能直接证明：

- 品牌或主体被正确记住；
- 公众理解了正确意义；
- 产品差异被相信；
- 产生偏好、采用、留存或溢价；
- 形成可控制的长期资产。

因此平台好而 IP 资产差、平台差而小样本资产信号好，都必须允许存在。

### 12.3 识别资产的专门测量

对每个语言、视觉、声音、角色、空间或仪式候选，保存：

- `fame`：目标公众中有多少人把它与主体联系；
- `uniqueness`：联系到主体的人中，有多少不同时想到竞争者；
- `meaning_accuracy`：联想到的意义是否正确；
- `polarity`：联想是正面、负面还是争议；
- `cross_context_robustness`：静音、小图、短时、不同平台是否成立；
- `combination_effect`：多个线索组合是否比单项更强；
- `decay_or_wearout`：随时间和重复如何变化。

### 12.4 试验纪律

- 发布前冻结假设；
- 一次主要改变一个战略变量，或明确使用多因素设计；
- 对重要差异至少比较 2–3 个实质候选；
- 不用早期噪音下永久结论；
- 不删除失败；
- 同一发布的多个时间窗只算一个独立作品证据；
- 一个爆款只能提高候选优先级，不能直接成为永久规则；
- 跨主体 portable 规则需要跨主体证据和留出回归。

## 十三、真正的壁垒飞轮

```text
专有事实、产品、关系和权利
            ↓
相对竞争差异与战略取舍
            ↓
主体专属戏剧发动机与表达语法
            ↓
可识别、可归因、可变化复现的作品与体验
            ↓
平台、资产、关系、采用与商业观察
            ↓
不可变预测—结果比较
            ↓
主体专属规则 + 匿名跨主体机制学习
            ↓
更快、更准、更难复制的下一轮差异判断
```

### 13.1 竞争者容易复制什么

- 一个提示词；
- 一种调色；
- 一个热门结构；
- 一个标题公式；
- 一条广告；
- 某个模型；
- 公开的电影术语；
- Skill 名称和目录。

### 13.2 竞争者更难复制什么

- 用户真实事实、产品、关系和权利图；
- 经过选择和失败形成的战略取舍；
- 多年人物、产品、角色和世界状态；
- 公众已经形成的独特资产联想；
- 每次内容绑定的不可变预测、版本和结果；
- 哪种机制对哪类主体、公众、情境有效的专有学习；
- 同一主体在不同时期的表达连续性和信任历史；
- Agent 在证据不足时拒绝伪确定性的纪律。

### 13.3 我们的电影库如何进入壁垒

358 部影片、393 位创作者或团队、304 张机制卡本身不是壁垒；公开电影都能被别人研究。
壁垒来自：

1. 把机制卡按“差异功能”重新标注，而不只按工种和类型检索；
2. 记录何种机制被用在何种 IP 载体、公众、资源和风险条件下；
3. 把机制组合与真实结果绑定；
4. 匿名学习成功与失败，不泄露用户证据；
5. 用学习结果改善路由，同时保留人类选择和可解释依据。

建议新增机制标签：

```text
differentiation_function:
  value_proof
  point_of_view
  relationship_engine
  category_inversion
  emotional_promise
  memory_structure
  ritual
  world_rule
  sonic_identifier
  visual_identifier
  product_dramatization
  serial_generativity

category_distance:
  direct
  adjacent
  distant

copy_risk:
  generic_mechanism
  combination_sensitive
  identity_bearing_exclude
```

## 十四、现有 Skill 的具体整改

### P0：建立差异化决策层

#### 1. 新增或重构 `design-ip-differentiation`

职责：

- 构建竞争对比场；
- 生成实质不同的候选；
- 强制保存取舍、证明、戏剧发动机、识别资产和失败条件；
- 编译 `ip-differentiation-thesis-v1`；
- 不直接写最终成片。

#### 2. 重构 `ip-strategy-director`

使其：

- 从通用 IP 实体图读取人物、品牌、产品、角色、方法和组织；
- 将商业模式、目标公众、目标影响、经济目标与差异命题分层；
- 不再用一个 `difference` 文本承载所有差异；
- 不再默认所有主体通过个人故事成立；
- 把采用的差异版本写入策略关系，而非复制字段。

#### 3. 建立后端 repository 与原生工具

至少：

```text
ip_differentiation_theses
ip_creative_bibles
ip_expression_systems
ip_equity_observations
```

以及：

```text
record/read/adopt/retire differentiation thesis
compile/read creative bible
compile/read expression system
record/read IP equity observation
compare thesis versions
```

主体、版本、采用状态、证据引用和权限必须由服务端控制。

### P0：升级对标与研究

#### `reference-media-analysis`

增加上游输出：

- `category_convention`；
- `identity_bearing_element`；
- `transferable_mechanism`；
- `territory_already_owned`；
- `anti_benchmark_reason`。

#### `video-pattern-learning`

增加约束：

- 生成 pattern 前读取采用的差异命题；
- 显式判断 pattern 会强化还是稀释主体差异；
- 实验性外部 pattern 不得覆盖主体不变项；
- portable pattern 不代表适合所有主体；
- 胜者模式学习必须同时保留失败和未归因结果。

#### `query-cinematic-library`

增加差异功能、类别距离和身份复制风险标签，并支持：

- 一项直接同类机制；
- 两项远距补充机制；
- 一项反例或失效机制；
- 一项低成本可实现机制。

### P1：让电影化 Skill 消费统一命题

以下上游模块应读取 `ip-differentiation-thesis-v1`：

- `engineer-desire-behavior`
- `develop-theme-premise`
- `design-character-relations`
- `route-ip-genre-engine`
- `shape-ip-emotion`
- `engineer-plot-information`
- `design-ip-series-bible`

并在输出中标明：

- 使用了哪个差异版本；
- 强化的是价值、意义、戏剧、识别还是证明；
- 哪个主体获得归因；
- 哪些是策略不变项；
- 哪些是本集可变项；
- 是否引入新的混淆或复制风险。

### P1：让工种 Skill 形成跨部门识别系统

导演、摄影、光色、美术、声音、表演和剪辑不应各自“做得独特”。它们要共享：

- 一句话表达命题；
- 3–7 个跨部门不变项；
- 可变范围；
- 禁止组合；
- 主体归因目标；
- 静音/无图/小屏/短时暴露的降级策略。

例如角色、固定空间、动作仪式、声音标记和光色关系可以共同编码同一主体，但不能同时
争抢注意。

### P1：升级广告和校准

#### `product-ad-production`

在 concept score 中把：

- value difference；
- brand/subject attribution；
- proprietary proof；
- copy defensibility；

分开，不只一个 `brand distinctiveness`。

#### `brand-launch-film-production`

要求读取已采用差异版本；manifesto、category contrast 等路线不能自行制造新战略。

#### `ip-content-calibration`

增加最早失败层：

```text
different-value
different-meaning
proof
dramatic-generativity
distinctive-attribution
extension
defensibility
```

并把平台表现、内容效果和 IP 资产结果分开。

### 不应新增

不为以下内容各建一个 Skill：

- 视觉差异；
- 声音差异；
- 人设差异；
- 品牌差异；
- 产品差异；
- 角色差异；
- 爆款差异。

它们是同一差异命题的 subtype、字段、研究模式和下游编译结果。继续按名词增包会制造新的
路由冲突。

## 十五、产品验收门槛

### 15.1 契约验收

- 差异命题是版本化后端真相，不只在聊天；
- 一个版本明确主体、公众、类别、替代、同类点、价值差异、意义差异、证明、取舍、
  戏剧发动机、独特资产和失败条件；
- 人物、品牌、产品、角色、方法和组织均可使用，不被个人字段阻断；
- 任何脚本、成片和发布都能追溯到采用版本；
- 旧版本只读可追溯，不能覆盖。

### 15.2 行为验收

至少用以下对抗案例验证：

1. 两个能力相近的专家，系统必须找到真实差异或诚实承认证据不足；
2. 一个没有功能创新的成熟品牌，系统能建立识别资产而不虚构 USP；
3. 一个产品有真实机制差异但品牌表达高度同质；
4. 一个视觉非常独特但产品价值和证明很弱的品牌；
5. 一个有爆款但无人记住主体的账号；
6. 一个角色比母品牌更出名，发生归因遮蔽；
7. 一个创始人强、产品弱，不能用人物魅力掩盖产品；
8. 一个产品强、创始人不出镜，仍能建立 IP；
9. 一个热点格式短期高流量但稀释差异；
10. 一个竞争者复制表面创意后，原主体仍保持识别和证明优势；
11. 一个差异候选无法通过 12 集测试，被拒绝；
12. 一个极端新奇候选缺少解释桥，被降级而非包装成大胆。

### 15.3 研究验收

- 对标集合同时包含类别、竞争者、替代、远距机制和反对标；
- 观察、推断、假设和行业启发式严格分开；
- 外部研究记录来源、日期、样本和局限；
- 广告供应商或研究公司的专有主张不被表述为普遍科学定律；
- 电影研究只迁移机制，不复制身份表达；
- 类别陈词滥调账本随时间更新。

### 15.4 创作验收

- 交换测试不是全部通过；
- 强承诺都有证据；
- 至少能生成 12 个非重复事件；
- 视听不变项与可变项清楚；
- 产品或目标主体不会被故事、明星、音乐和角色遮蔽；
- 作品在静音、小屏、短时、跨比例下仍保留最低识别；
- 电影化选择能解释其战略功能，不使用“更高级”作为理由。

### 15.5 观察验收

- 平台、归因、意义、关系、选择、商业和采用结果分开；
- 缺失保持缺失，不变成零；
- 一次爆款不能验证永久差异；
- 资产候选保存 fame、uniqueness、meaning accuracy 和混淆；
- 差异版本的保留、修订、退役有不可变证据；
- 跨主体学习匿名、带范围、可回滚。

## 十六、实施优先级

### P0-A：先建差异命题，不先扩拍摄能力

1. 定义 `ip-differentiation-thesis-v1`；
2. 建 repository、迁移、read model 和原生工具；
3. 建 `design-ip-differentiation`；
4. 重构 `ip-strategy-director` 与通用 IP 实体图衔接；
5. 为旧 creator 策略生成可追溯迁移版本，未知保持未知。

### P0-B：建竞争对比研究

1. 新增竞争领地与类别陈词滥调输出；
2. 对标 intake 强制五类对比；
3. 本地电影库增加差异功能与复制风险标签；
4. 用 3 个真实类别完成研究回放；
5. 对输出做模仿和权利审查。

### P0-C：编译创作真相

1. 建 `ip-creative-bible-v1`；
2. 建 `ip-expression-system-v1`；
3. 给基础电影化模块加差异版本输入与交接字段；
4. 给工种模块加跨部门 invariants/variables；
5. 用人物、品牌、产品各跑一个端到端样例。

### P1-A：补 IP 资产观察

1. 建识别、归因、意义、偏好、采用、延展的观察契约；
2. 支持平台、问卷、访谈、CRM、销售、产品分析和人工证据；
3. 让校准系统定位差异层失败；
4. 建差异版本对比和退役规则；
5. 不把供应商基准硬编码成产品真理。

### P1-B：形成机制学习壁垒

1. 将每条发布与差异、圣经、表达、脚本和制作版本绑定；
2. 保留成功与失败；
3. 匿名生成条件化机制观察；
4. 先做主体内学习，再做跨主体 portable 规则；
5. 建留出回归、回滚和漂移检测。

## 最终判断

用户说得对：

> **帮用户做 IP 只是能力，帮用户形成差异化 IP 才可能成为壁垒。**

但“差异化”的正确实现，不是再增加几个取名、定位、爆款或电影风格 Skill。现有 35 个
电影化 Skill 的价值也不是数量，而是它们能把一个真实差异命题编译成：

- 有代价的选择；
- 不可互换的人物与关系；
- 独有的视点、信息和情绪承诺；
- 可反复演化的世界、事件和仪式；
- 可跨作品识别的语言、视觉、声音和行为语法；
- 能通过作品、产品与经营结果被持续验证的资产。

因此下一阶段的架构重点应是：

```text
通用 IP 实体图
→ 专有事实与竞争对比
→ 版本化差异命题
→ 电影化创作圣经与表达系统
→ 广告任务与试验组合
→ 正确归因、意义、关系、采用和商业观察
→ 不可变学习与版本演化
```

当这条链跑通以后，别人可以复制我们的一个镜头、一个标题、一个模板，甚至看到部分 Skill；
但很难复制某个用户长期积累的事实、选择、关系、识别资产、作品世界和预测—结果学习历史。
这才是 IP Agent 值得建设的产品壁垒。
