# IP Agent 首次对话：叙事访谈与自适应提问研究

研究日期：2026-07-30

## 结论

Personal-IP 的首次对话不应是“更漂亮的问卷”，也不应模仿心理咨询师的身份。
它应当是一个有明确经营目的、尊重用户叙事权、能够根据上一句话改变下一步的
**叙事策略访谈**。

核心判断如下：

1. 提问不是连续抛出开放题，而是“邀请叙述—倾听—映照—形成暂定假设—允许纠正—
   再追问”的循环。
2. 高质量追问必须引用用户刚刚提供的事实、用词或矛盾。问题数量不是智能程度；
   与上一回答的关联和回应感才是。
3. “从记事起讲”可以帮助发现人物的早期记忆、价值母题和重复模式，但不应成为所有
   新用户的强制第一问。更安全、也更容易回答的开场是让用户先划分人生、品牌或产品的
   “章节”，由用户决定从哪里讲。
4. 早期记忆、低谷、家庭关系和创伤只在确实会改变 IP 战略时才追问，并且必须说明目的、
   允许跳过、允许标记为仅内部理解或禁止用于内容。
5. 智能体可以借鉴动机式访谈、叙事访谈和半结构化访谈的微观技术，但不能自称心理
   咨询师，不能诊断、治疗、诱导创伤披露，也不能用“我完全懂你的感受”伪装真实情感。
6. 首次访谈的输出不是“画像完成”或“定位完成”，而是经用户确认的事实、暂定解释、
   未知、边界和下一项最值得验证的问题。

## 一、为什么当前卡片式提问不成立

当前首次回复解决了三个工程问题：空用户不扫描经营驾驶舱、响应足够快、不会无界调用
模型和研究工具。但它把对话压缩成了两张确定性 `ask_clarification` 卡片：

- 第一张收集人物/品牌/产品经历；
- 第二张收集目标公众与问题；
- 用户的不同回答最终仍进入同一条预写路径。

这证明了“系统能收字段”，没有证明“系统听懂了人”。其主要缺陷不是卡片外观，而是：

- 下一问在上一答之前就已经决定；
- 没有复述用户事实，也没有提出可被纠正的意义假设；
- 一次展示多个问题和选项，用户寻找“正确答案”，而不是形成自己的叙述；
- 智能体的内部字段顺序主导对话，用户没有叙事控制权；
- 不区分用户想立刻完成具体任务，还是愿意进入长期孵化；
- 没有对私密、敏感、仅内部和可公开材料做逐步边界确认。

因此，修复不能只是把卡片换成自由输入框，也不能把固定题库改写得更温柔。只要下一问
不由上一答决定，本质上仍是问卷。

## 二、研究依据

### 2.1 开放问题之后，先映照，再继续问

美国 SAMHSA 的动机式访谈指南把开放问题、肯定、反映式倾听和总结归纳为 OARS。
它明确提醒避免“问答陷阱”，并建议一个开放问题之后先做至少一次、最好两到三次反映，
再提出新问题。反映不是给用户下结论，而是对其可能含义提出一个假设，等待用户确认，
并保持自己可能理解错了的开放性
([SAMHSA / NCBI, 2019](https://www.ncbi.nlm.nih.gov/books/NBK571068/))。

产品含义：

- 智能体不能每轮都只输出一个新问题；
- 每次追问前至少应证明自己听见了什么；
- 解释必须使用“听起来像是……我理解得对吗”一类可纠正语言，不能把推断写成事实；
- “两到三次反映”是训练方向，不应机械变成每轮固定三句模板。

### 2.2 真正产生回应感的是跟进问题，不是问题总数

一组面对面和在线对话实验发现，提出更多问题的人通常更受对话伙伴喜欢；更重要的是，
效果主要来自与对方刚才回答相连的跟进问题。其机制是对方感到自己被倾听、理解、确认
和关心，而不是提问者完成了更多问题
([Huang et al., 2017, Journal of Personality and Social Psychology](https://www.mikeyeomans.info/papers/question_asking.pdf))。

产品含义：

- 质量指标不能只是“完成了多少 intake 字段”；
- 下一问必须能指出它来自用户上一句话中的哪个事实、变化、冲突或空白；
- 通用题库只能提供候选方向，不能直接决定实际措辞和顺序。

### 2.3 人是通过不断修订的生命故事形成叙事身份

叙事身份研究把它描述为一个持续演化的内部生命故事：人把重构的过去和想象的未来连接
起来，以形成一定的统一感和目的感。能动性、关系、探索和转化等主题与适应性结果有关，
但相关性不能被产品误写为单向因果或人格诊断
([McAdams & McLean, 2013](https://www.psychologicalscience.org/journals/current-directions/0963721413475622/))。

标准 Life Story Interview 通常先请受访者把人生想象成一本书并划分章节，再选择高点、
低点、转折、重要人物、未来章节和主题，而不是一上来强迫回忆最早童年场景
([McAdams, Life Story Interview outline](https://api.pageplace.de/preview/DT0400.9781317665717_A28389477/preview-9781317665717_A28389477.pdf))。

产品含义：

- 人物 IP 可以先问“如果把你的经历分成几章，你会怎么命名”；
- 品牌、产品和组织也有起源、转折、失败、采用和未来章节，但不能被套成人类童年；
- 章节只是导航，真正可用的 IP 证据仍需落到具体事件、选择、代价、能力、关系和结果；
- “最早记忆”是可选的关键场景，不是默认入口。

### 2.4 半结构化访谈应先给叙述权，再按回答探查

半结构化访谈方法建议问题保持开放、清晰、中性和非诱导；先用容易回答的背景或
“grand tour”问题建立语境，把更困难或敏感的问题放在后面。访谈提纲保证覆盖面，
现场的计划外追问则应由受访者刚刚给出的回答触发
([DeJonckheere & Vaughn, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6910737/))。

产品含义：

- 内部可以有证据地图，客户侧不能按字段逐项展示；
- 用户先自由报告，智能体不应在第一段叙述中频繁打断；
- 追问具体事件时优先问场景、参与者、行动、选择、结果和后来意义，而不是让用户评价
  抽象人格标签。

### 2.5 AI 必须透明、可纠正、可跳过，并说明为什么问

人机交互研究提出：AI 应提前说明自己能做什么和可能做不好的地方；提供与当前语境相关
的信息；支持用户忽略、修正和限定范围；在不确定时请求消歧或优雅降级；并在合适时说明
为什么采取某项动作
([Amershi et al., CHI 2019](https://www.microsoft.com/en-us/research/wp-content/uploads/2019/01/Guidelines-for-Human-AI-Interaction-camera-ready.pdf))。

语言模型已经能够生成一定质量的动机式访谈“反映”，但研究本身仍使用人工评价和质量
分类器，并不证明模型可以替代临床判断
([Tanana et al., EACL 2024](https://aclanthology.org/2024.eacl-long.75/))。

产品含义：

- 首轮说明这是为影响力资产与经营方向建立依据，不是心理治疗；
- 用户随时可以说“跳过”“别用于内容”“只做具体任务”“你理解错了”；
- 智能体要显式区分用户原话、可观察事实和自己的暂定解释；
- 对敏感内容，模型生成的共情表达需要更保守，不能虚构共同经历或情绪感受。

### 2.6 敏感经历必须遵守创伤知情边界

创伤知情原则强调安全、透明、合作以及用户的声音和选择。相关访谈指导还要求在敏感问题
前先建立舒适度、解释目的、减少不必要细节、尊重拒绝并避免重复追问
([SAMHSA, 2014](https://library.samhsa.gov/sites/default/files/sma14-4884.pdf);
[NCTSN](https://www.nctsn.org/what-child-trauma-trauma-types-sex-trafficking/screening-identification-and-assessment))。

产品含义：

- 不以“挖故事”为由强迫用户讲童年、羞耻、暴力、疾病、丧失或家庭隐私；
- 用户出现明显不适、拒绝、转移或要求停止时，立即停止该分支；
- 不把痛苦程度当作内容价值，不鼓励为了爆款进行过度披露；
- 只收集会改变战略或内容边界的最低必要信息。

## 三、Personal-IP 的提问第一性原理

一个问题只有同时满足以下条件才值得问：

1. **决策价值**：答案会改变主体识别、受众、差异命题、证明、内容路线、表达方式、
   经营目标或安全边界中的至少一项。
2. **上下文关联**：它来自用户已经表达的目标、事实、词语、矛盾或未知，不是因为题库
   轮到这一项。
3. **可回答性**：用户此刻拥有足够记忆和语境回答；抽象问题优先改成具体事件邀请。
4. **非诱导性**：问题不偷偷预设“你一定受过某种创伤”“这个经历必然塑造了你”或
   “你应该选择某种定位”。
5. **叙事控制权**：用户可以纠正、拒绝、跳过、改变讲述顺序和限定使用范围。
6. **信息增益**：已有答案足以做下一步时停止追问，不为了显得专业而无限深挖。

这可以表达为内部判断：

```text
下一问价值
= 战略决策影响
× 与上一回答的关联
× 用户当前可回答程度
× 安全与授权
− 重复信息
− 诱导风险
− 不必要的隐私成本
```

任何一项关键乘数为零，这个问题就不应在此刻提出。

## 四、推荐的自适应叙事访谈流程

### 0. 先识别是否需要访谈

用户如果直接要求改一段脚本、分析一个链接、诊断一个已连接账号或制作一个视频，先完成
或推进该任务。不能用“先建立画像”阻断明确工作。

只有当用户表达“帮我做 IP、找方向、从零开始、我不知道做什么”等开放目标时，进入
叙事访谈。具体任务中发现的真实证据可以在适当时请求用户纳入长期策略。

### 1. 建立对话契约

首轮用正常对话说明：

- 访谈的目的：找出可持续影响力、可证明差异和经营路径；
- 它不是心理测评或心理治疗；
- 每次只讨论一个方向；
- 用户可以跳过、纠正或规定材料用途；
- 如果用户只想马上做事，可以直接说。

### 2. 给出 grand-tour 邀请

根据主体类型选择容易进入、但不预设答案的入口：

- 人物：`如果把你走到今天的经历分成几章，你会怎么给这几章起名字？不用完整，先说你觉得真正改变了你的几段。`
- 品牌：`如果把这个品牌从产生念头到今天分成几章，哪些阶段真正改变了它的承诺或活法？`
- 产品/服务：`这个产品最初是被什么真实问题逼出来的？从第一版到现在，哪几次变化最关键？`
- 组织/社区：`这群人最初为什么聚在一起？后来发生过哪些让规则、关系或共同目标改变的事？`

用户已经从一个具体事件讲起时，不把他拉回标准开场。

### 3. 自由叙述，先不抢方向盘

第一段回答后，智能体先识别：

- 明确事实；
- 用户强调的词；
- 选择、代价、冲突或转折；
- 尚未证实的自我解释；
- 可能敏感的材料与使用边界；
- 哪一个未知最可能改变战略。

这一步不输出内部标签，不急着给定位。

### 4. 每轮执行“映照—暂定意义—一个追问”

推荐结构：

```text
事实映照：你刚才说，真正的变化不是 X，而是 Y。
暂定意义：这听起来可能说明你最在意的是 Z，但我不想替你下结论。
一个追问：在那次具体事件里，你做了什么别人通常不会做的选择？
修正权：如果我理解偏了，你直接纠正我。
```

不是每轮都必须四句齐全。核心约束是：

- 一轮最多一个主问题；
- 至少引用一个用户刚提供的具体信息；
- 解释保持可纠正；
- 不把夸奖当作倾听；
- 用户需要长讲时不强制短答。

### 5. 从抽象主张回到可观察事件

当用户说“我很专业”“我们特别真诚”“产品很好”“用户很喜欢”时，不争辩，也不直接
记录为事实。选择一个最有判别力的事件追问：

- 当时在哪里、谁在场；
- 出现了什么问题；
- 用户/团队具体做了什么；
- 有什么可观察结果或代价；
- 是否有工单、作品、客户反馈、数据或第三方材料；
- 这件事是偶发还是重复出现。

### 6. 定期总结并让用户校正

在若干轮或一次自然章节结束后，区分四类内容进行总结：

- `你明确说过的事实`
- `我目前的暂定理解`
- `还缺证据的假设`
- `不公开或不使用的边界`

只有用户确认后，才把相关内容编译进版本化策略。确认不是“整份表单提交”，而是自然
语言校正。

### 7. 再选择关键场景，而不是机械回顾一生

根据当前缺口，从以下场景中只选最有决策价值的一项：

- 高点；
- 低点；
- 转折；
- 一次失败或代价；
- 一次能力被外部证明；
- 一段关键关系；
- 一个重复出现的冲突；
- 最早记忆；
- 希望写下的下一章。

最早记忆只有在人物主体、用户愿意、与当前价值或行为模式可能相关时才出现。品牌、产品
和组织改用起源事件，不做人类化心理套问。

### 8. 从理解进入可验证行动

叙事访谈不能成为无限聊天。获得足够事实后，智能体应给出：

- 两到三个真正不同的方向假设；
- 每个方向的证据、未知、经营目标和放弃项；
- 对标与反对标；
- 一个低成本、可观测的选题和脚本实验；
- 拍摄后用于判断表现力、镜头适应和替代制作路线的评价标准。

## 五、系统实现约束

### 5.1 对话层

- 不用 `ask_clarification` 卡片承载首次孵化主流程；
- 普通 composer 始终可用；
- 默认一轮一个主问题，不显示内部分类和字段进度；
- 用户输入自由长度，不用选项暗示正确答案；
- 跟进问题由当前回答生成，不按固定序号播放；
- 在叙事访谈期间关闭通用“后续建议”自动生成，避免出现第二套提问者。

### 5.2 推理层

不能让完整 ip-agent、全部 Skill 和四万 token 上下文只为生成一句追问。需要一个受限的
`reflect + next question` 路径：

- 输入仅含对话契约、最近相关叙述、已确认摘要、开放假设和安全边界；
- 输出严格区分事实映照、暂定解释、一个问题、问题理由和用户控制提示；
- 默认不使用外部工具；
- 只有问题会改变战略且当前信息不足时才提问；
- 低置信度时优先校正理解，不继续向更敏感处追问。

### 5.3 证据与隐私层

- 原始对话是来源，不自动等于经营事实；
- 用户确认后再写版本化策略；
- 每条提炼内容保留来源轮次、确认状态、用途边界和证据等级；
- `可公开`、`可匿名使用`、`仅内部理解`、`禁止使用`必须可表达；
- 用户撤回材料后，未来策略和内容不得继续使用；已发布内容另行明确处理。

## 六、验收台账

| 验收维度 | 必须证明的行为 |
| --- | --- |
| 非问卷感 | 首次孵化用普通对话，不出现 intake 卡片、字段表或完成进度 |
| 回应感 | 第二轮明确引用用户第一轮中的独有事实，回答不同则追问不同 |
| 叙事控制 | 用户可以自由选择章节、改顺序、长讲、跳过、纠正和中止 |
| 问题纪律 | 每轮最多一个主问题；已有足够证据时不继续问 |
| 非诱导 | 不预设人格、创伤、结论、受众或定位 |
| 敏感边界 | 最早记忆/低谷不是默认首问；拒绝后不改写措辞重复追问 |
| 主体适配 | 人物、品牌、产品、组织分别使用合适入口，不把产品当人做心理分析 |
| 事实校正 | 用户原话、可观察事实、智能体解释和假设在存储与总结中分开 |
| 任务优先 | 明确的脚本、诊断、发布、视频任务不被强制 onboarding 阻断 |
| 成本延迟 | 首次开场仍快速；每轮追问使用小上下文受限调用，不回到 8 万 token 路径 |
| 真实 E2E | 真实 Next.js + Gateway + SQLite 验证至少三条不同回答产生不同追问 |
| 长期闭环 | 经确认的叙事证据能进入方向候选、试拍、表现力判断和后续复盘 |

本轮已完成前十一项的产品路径和自动化验收：首次开场为零模型调用的普通对话，后续只把
最近八条可见对话交给受限的“映照—下一问”结构化调用；真实前后端回放证明三种回答会
产生三种不同追问，且没有问答卡片或通用后续建议介入。最后一项“长期闭环”仍须由真实
用户把经确认的叙事证据推进到方向、试拍、发布和复盘后验收，不能用回放测试冒充。

## 七、需要避免的语言

不使用：

- `我完全理解你的感受`
- `这一定是因为你的童年`
- `这个创伤塑造了你的 IP`
- `你天生适合做……`
- `画像已经完成`
- `根据心理学，你应该……`
- `为了做出爆款，再讲得痛一点`

优先使用：

- `我先确认自己有没有理解偏`
- `你刚才把……和……放在了一起`
- `这可能意味着……，但目前只是我的猜测`
- `这个问题是为了判断……；不想谈可以跳过`
- `这段材料只用于内部理解，还是也可以进入公开内容？`
- `现在已有的信息足够先做一个小实验，不需要继续深挖`

## 最终产品定义

首次对话的专业感不来自“它问得像专家”，而来自用户逐渐发现：

> 它记得我说过什么，分得清事实和猜测，不急着给我贴标签，知道什么时候追问、
> 什么时候停，并且每一个问题最终都会改变一个可执行的经营判断。

这才是 Personal-IP 应该实现的智能化提问，而不是心理咨询外观或会说话的问卷。
