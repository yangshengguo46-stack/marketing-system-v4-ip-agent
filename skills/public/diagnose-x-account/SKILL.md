# Diagnose X account

Use this for a concrete X account. Read `references/platform-evidence.md` first.

1. Read `personal_ip_account_diagnostic_context`.
2. Use available evidence without waiting for complete coverage or a compiled verdict.
3. Diagnose IP type, audience promise, desire/conflict, story and expression
   form before immediate comprehension, conversation value, trust, intent and conversion.
4. Inspect Following versus For You, network fit, freshness, eligibility and
   negative feedback separately. X's open source describes architecture, not a
   guaranteed formula or stable public weights.
5. Lead with continue, adjust, or start separately. Explain the decisive
   content/business reason, platform context, uncertainty and next content move.

Do not impose a fixed sample size.
