# X platform evidence

Last reviewed: 2026-07-30. Prefer current repository revisions and live account
status over older Twitter-era explanations.

## Official evidence

- [xAI X recommendation repository](https://github.com/xai-org/x-algorithm)
  is the current open-source implementation entry. The 2026 architecture
  combines in-network and out-of-network candidate retrieval and predicts
  engagement outcomes for ranking.
- [X recommender-system overview](https://help.x.com/en/resources/recommender-systems)
  describes recommendation surfaces and personalization.
- [X recommendation policy](https://help.x.com/en/rules-and-policies/recommendations)
  explains recommendation eligibility and safety; being allowed on X does not
  guarantee amplification.
- [X Search recommendations](https://help.x.com/en/resources/recommender-systems/search-recommendations)
  describes relevance, engagement, quality/health and personalization inputs.

## Diagnosis use

Separate Following, For You, Search and conversation distribution. Inspect
current eligibility, negative feedback, in/out-of-network traffic, replies,
reposts, quotes, profile actions and commercial outcomes.

The open-source system explains architecture, not a permanent public weight
table or guaranteed recipe. The historical `twitter/the-algorithm` repository
is not current product truth. Low impressions alone do not prove account-level
suppression.
