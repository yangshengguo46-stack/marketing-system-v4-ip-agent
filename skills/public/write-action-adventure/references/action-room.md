# 动作与冒险

## 动作节点

`目标 → 路径 → 障碍 → 可用资源 → 策略 → 后果 → 新地理/新限制`

每一段都应改变至少一项，不能只是更大规模重复。

## 空间

- 建立入口、出口、方向和相对位置；
- 关键物件出现后保持可追踪；
- 打乱地理前先让观众知道规则；
- 群体行动先分阵营与功能；
- 速度越快，构图与接点越需简单。

黑泽明被专业分析为先建立信息、地点和视觉规则，使战斗空间清楚：[DGA](https://www.dga.org/craft/dgaq/issues/0603-fall-2006/screening-room-darren-aronofsky)。

乔治·米勒强调单个镜头服从视觉句子流动：[DGA](https://www.dga.org/Events/2024/July2024/Furiosa_QnA_0524)。

## 人物

- 强者也需限制；
- 团队每人解决不同问题；
- 失败必须改变后续资源；
- 动作可以是拒绝、保护、等待或放弃，不只攻击；
- 身体疲劳和伤害要影响下一段。

## 个人IP

挑战、改造、旅行、学习和创业都可用动作结构。真实安全优先；危险动作不因“电影感”升级，使用预演、替代镜头和剪辑表达。
