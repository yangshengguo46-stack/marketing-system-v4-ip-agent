# 动作冒险编剧室

动作是人物为了欲望在物理条件下采取的策略和选择。先让观众理解欲望、目标、地理和风险，再加速度。

## 工作流

1. 写人物为什么必须从A到B；
2. 画地点、路径、出口、危险和资源；
3. 分配角色能力与限制；
4. 让每个障碍要求新策略；
5. 用资源减少、时间和地理变化升级；
6. 让动作选择暴露性格或关系；
7. 设计可见后果和恢复；
8. 做安全与可拍性预演。

查阅 `references/action-room.md`。

## 输出

- 动作命题；
- 地理图；
- 目标/资源/限制；
- 障碍升级；
- 角色分工；
- 动作选择与人物差值；
- 镜头/剪辑/声音需求；
- 安全与降级方案。

不可用镜头晃动、快切和慢动作掩盖空间与因果。
