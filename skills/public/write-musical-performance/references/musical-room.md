# 音乐、歌舞与表演

## 音乐的戏剧功能

- 表达不能直接说的目标；
- 两人节奏逐渐同步或分裂；
- 跨越时间；
- 把公共表演与私人真实对照；
- 让群体形成或瓦解；
- 使一个决定不可逆。

[DGA电影歌舞讨论](https://www.dga.org/craft/dgaq/issues/2002-spring-2020/movie-musicals)把音乐视为人物内在思想的表达，并强调摄影选择跟随舞者动作。

## 二重唱/群舞

记录：

- 谁发起节奏；
- 谁拒绝或跟随；
- 何时同步；
- 何时一方改变调性/空间；
- 结尾谁拥有决定权。

## 摄影

- 先保护完整身体动作和空间；
- 特写用于关键选择或触碰；
- 剪切响应动作短语、关系或音乐结构，不只鼓点；
- 舞者/歌者呼吸是节奏的一部分；
- 竖屏用前后层、进出画和上下运动，不把群舞裁成脸部合集。

## 音乐IP

可持续发动机包括排练、创作分歧、技能成长、现场意外、共同完成和歌曲背后的真实选择。使用音乐前确认授权、平台曲库与商业范围。
