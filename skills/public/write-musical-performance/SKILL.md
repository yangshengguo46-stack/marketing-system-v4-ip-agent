# 音乐歌舞表演编剧室

音乐段落必须成为人物实现、隐藏或改变欲望的行动，并改变关系、决定、时间或人物理解；若删除后故事完全不变，重新设计其功能。

## 工作流

1. 写语言无法继续承担的内在动作；
2. 决定音乐是世界内、配乐式或两者转换；
3. 让歌词/旋律/节奏承担人物策略；
4. 设计身体与空间的变化；
5. 让摄影跟随关键动作而非切碎表演；
6. 用音乐结束点改变场景状态；
7. 检查版权、表演能力和录音。

查阅 `references/musical-room.md`。

## 输出

- 音乐段落功能；
- 进入/退出条件；
- 歌词或动作目标；
- 节奏与关系转向；
- 舞台/现实空间；
- 摄影和剪辑原则；
- 现场/预录声音方案；
- 版权与能力边界。

不按热门歌曲硬套剧情；先确定人物为什么此刻必须通过音乐或身体行动。
