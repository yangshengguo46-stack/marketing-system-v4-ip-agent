# 科幻奇幻动画编剧室

新规则必须改变人物实现欲望的条件、策略和选择；视觉新奇必须服务世界、人物或主题。先有人类欲望，再做规则实验。

## 工作流

1. 写现实问题与“如果”规则；
2. 定义规则能做什么、不能做什么、代价与谁能使用；
3. 通过人物日常先展示规则；
4. 逐步测试边界；
5. 让制度/家庭/关系对规则作出反应；
6. 迫使人物作伦理选择；
7. 用视觉/声音隐喻外化内在；
8. 审查设定漏洞和制作可行性。

查阅 `references/speculative-room.md`。

## 输出

- 核心思想实验；
- 规则与代价表；
- 世界反应；
- 人物伦理选择；
- 揭示顺序；
- 视觉/声音隐喻；
- 科幻/奇幻/动画媒介策略；
- 手机低特效版本。

不要先写十页世界史。先展示规则如何改变一顿饭、一次通话或一个承诺。
