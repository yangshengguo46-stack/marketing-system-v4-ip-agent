# 科幻、奇幻与动画

## 规则卡

- 规则一句话；
- 首次可见现象；
- 使用条件；
- 硬限制；
- 代价；
- 谁获益、谁受损；
- 社会/家庭反应；
- 极端测试；
- 最终伦理选择。

## 科幻

从技术/认知新规则追问“何为人、记忆、时间、身份、劳动或关系”。《降临》的视觉策略服务“闹鬼但有希望”的时间与记忆体验，而非只制造外星表面。[ASC](https://theasc.com/articles/arrival-cinematography-bradford-young)

## 奇幻/神话

- 契约、门槛、变形、禁令和归来；
- 魔法代价必须影响关系或身份；
- 神话母题需经过用户文化与现实问题转译；
- 不把陌生文化符号当装饰。

## 动画

动画可用形变、尺度、材质和物理规则让内在可见。每次媒介自由都问：

- 真人实拍为什么做不到或不如它？
- 形变是否改变因果？
- 视觉节奏是否仍可理解？

[Pixar in a Box](https://www.pixar.com/pixar-in-a-box)把世界与人物作为故事训练入口；[Academy Academy](https://www.oscars.org/videos-photos/academy-academy)提供动画与摄影/美术等工种基础。

## 低成本IP

- 一条语言禁令；
- 一个每天变化的物件；
- 时间/记忆的重复剪辑；
- 角色看得见、他人看不见的声音或字幕；
- 同一空间在规则改变前后的行为差异。
