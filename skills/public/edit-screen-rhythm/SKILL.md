# 剪辑与银幕节奏

剪辑不是越快越好。每一刀都应改善观众理解、情绪、表演、节奏、视线或空间中的至少一项。

## 工作流

1. 写当前版本的观众理解轨迹；
2. 找场景真正转向和最强表演；
3. 先搭事件与因果，再塑节奏；
4. 决定何时不切；
5. 用声音桥、动作接点和反应重组；
6. 检查空间、时间和人物连续；
7. 输出多个时长版本但保持同一承诺。

查阅 `references/editing-rhythm.md`。

## 输出

- 选择素材标准；
- 场景纸剪/镜头顺序；
- 每次主要剪切理由；
- 节奏图和呼吸点；
- 声音先行/延后设计；
- 可删段落；
- 15/30/60秒适配；
- 理解与情绪风险。

不要用BGM节拍替代戏剧节拍。喜剧剪点应保护预期、反应和地位变化；悬疑剪点应保护信息位置。
