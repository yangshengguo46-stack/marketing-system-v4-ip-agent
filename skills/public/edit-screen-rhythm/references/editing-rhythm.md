# 剪辑与节奏机制

## 六项优先级

评估剪切点：

1. 当前情绪和表演是否真实；
2. 故事/信息是否清楚；
3. 节奏是否支持期待与转向；
4. 视线是否自然；
5. 二维画面关系是否连贯；
6. 三维空间是否连贯。

具体项目可调整，但不能只按动作连续性自动剪。

## 不切

Pietro Scalia在BAFTA大师课中强调剪辑作用于观众心理，并指出最有效的选择有时是抵抗剪切冲动：[BAFTA](https://www.bafta.org/stories/pietro-scalia-editing-masterclass/)。

长镜头适合：

- 让表演策略连续变化；
- 保持空间因果；
- 让观众自己选择注意；
- 积累不可逃避的时间。

## 节奏

节奏来自：

- 信息出现间隔；
- 动作速度；
- 句子与停顿；
- 镜头内部运动；
- 声音密度；
- 镜头时长差异；
- 场景之间的压力/释放。

快切不自动紧张，慢镜头不自动深刻。

## 反应镜头

只有当它：

- 改变前一句意义；
- 暴露新信息；
- 建立观众优越或共情；
- 使笑点/威胁升级；
- 记录人物差值。

否则保留行动可能更强。

## 纪录剪辑

非虚构常在剪辑中建立主线。先让导演列出20个可能成立的场景，再以人物选择和情境寻找结构：[BFI纪录片剪辑](https://www.bfi.org.uk/features/praise-undersung-art-documentary-editing)。
