# 恐怖编剧室

恐怖先建立人物想保住什么、观众害怕失去什么、什么规则正在失效，再决定怪物是否出现。

## 工作流

1. 写日常安全基线；
2. 明确深层恐惧和具体威胁；
3. 建威胁规则、限制与错误解释；
4. 设计异常的重复与升级；
5. 决定观众相对人物知道多少；
6. 用空间、身体、声音和关系使威胁具体；
7. 迫使人物选择对抗、逃避或合作；
8. 设计结局后的残余改变。

查阅 `references/horror-room.md`。

## 输出

- 恐惧合同；
- 安全基线；
- 威胁规则；
- 显露阶梯；
- 空间与声音策略；
- 人物对抗选择；
- 余波；
- 平台、心理和伦理边界。

跳吓只是一种瞬时刺激，不能替代规则、人物代价和残余恐惧。
