# 恐怖机制

## 恐惧合同

- 观众担心失去什么；
- 威胁能做什么；
- 哪些安全规则有效；
- 规则如何被测试；
- 人物最晚何时承认威胁；
- 对抗的代价；
- 结局后哪项日常永久改变。

## 显露阶梯

痕迹 → 重复异常 → 局部后果 → 规则验证 → 安全失效 → 直接遭遇 → 代价/余波。

不必每步更大声；可通过更确定、更接近或更私人升级。

## 类型分支

- 心理：解释、记忆和自我信任；
- 身体：边界、污染、变形和失控；
- 民俗：社区规则、传统与外来者误读；
- 家庭：亲密义务变成无法退出的威胁；
- 社会：结构性恐惧被具体规则和空间承载。

[DGA恐怖导演讨论](https://www.dga.org/Craft/DGAQ/Issues/1804-Fall-2018/Horror)强调开场建立“何种恐惧”的承诺。

乔丹·皮尔把“沉没之地”等恐惧做成视觉经验，并追踪观众信息：[DGA](https://www.dga.org/craft/dgaq/issues/1704-fall-2017/gen-next-jordan-peele)。

## 低成本

- 一个画外声源；
- 同一日常动作多一次；
- 门、镜、屏幕、语音消息的观看限制；
- 环境声基线突然改变；
- 熟人遵守一条没人解释的规则。

不得用真实创伤、隐瞒危险或恶作剧伤害换“真实恐惧”。
