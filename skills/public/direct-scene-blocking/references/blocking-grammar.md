# 场面调度语法

## 六种空间变量

| 变量 | 可见问题 |
|---|---|
| 距离 | 谁主动接近、谁被迫后退？ |
| 高低 | 谁占据台阶、坐姿、前后层级？ |
| 朝向 | 谁面对、回避、与谁同向？ |
| 领地 | 谁控制门、桌、车、镜头或关键物件？ |
| 遮挡 | 谁只能部分看见或被排除？ |
| 运动权 | 谁能自由走，谁被固定？ |

意义由场景建立，不把高位机械等同权力。

## 群戏

- 先建立阵营和共同焦点；
- 让每组人有不同空间目标；
- 用一人改变位置触发联盟重排；
- 关键反应可以在主镜头内发生，不必逐人特写；
- 群体混乱前先让观众理解地理。

黑泽明动作场面以清楚地理和阵营支持快速变化：[DGA分析](https://www.dga.org/craft/dgaq/issues/0603-fall-2006/screening-room-darren-aronofsky)。

## 两人戏

- 正面对峙：双方争取彼此；
- 并排同向：共同面对第三事物，但内部仍可分歧；
- 前后层：一人控制可见行动，另一人控制观察；
- 物件中介：递、夺、收、藏比说明关系更可拍；
- 转身/离开应有代价，不作装饰。

## 竖屏

- 优先前后纵深、上下层级、脸与手的错位；
- 避免两人长期左右平排挤在中央；
- 关键物件进入脸附近的可读区域；
- 走位保留字幕和平台UI安全区；
- 小空间用门框、桌边、镜面和前景建立领地。
