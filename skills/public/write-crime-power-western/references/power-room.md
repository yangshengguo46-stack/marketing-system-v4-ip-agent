# 犯罪、权力与边疆

## 权力五源

- 资源：钱、物、渠道、时间；
- 规则：能定义合法/违规；
- 信息：秘密、证据、专业知识；
- 关系：组织、群众、家族、客户；
- 行动：执行、退出、阻断或保护能力。

每个角色至少强一项、弱一项。

## 三方场

| 方 | 想要 | 掌握 | 公开身份 | 隐性底线 | 可替代联盟 |
|---|---|---|---|---|---|

任何两方结盟必须改变第三方成本。若第三方不影响局势，删掉或重写。

## 谈判

进入前目标 → 首次报价 → 试探底线 → 证明资源 → 改写身份/规则 → 暂时成交或破裂 → 新债务。

## 西部/边疆

旧规则失效 → 陌生人进入 → 资源/地盘争夺 → 社区选边 → 新规则建立 → 建立者是否离开。可转译为创业、新平台、迁居或行业变革，不保留枪战表面。
