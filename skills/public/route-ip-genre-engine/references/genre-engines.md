# 全球题材发动机

样本用于理解机制，不用于复刻标志性风格。经典片来源池交叉参考 [BFI](https://www.bfi.org.uk/sight-and-sound/greatest-films-all-time)、[WGA](https://www.wga.org/writers-room/101-best-lists/101-greatest-screenplays/list) 与 [ASC](https://theasc.com/news/asc-unveils-list-of-100-milestone-films-in-cinematography-of-the-20th-century)。

## 导航

- 1–5：悬疑、惊悚、犯罪、喜剧、爱情
- 6–10：家庭、成长、科幻、奇幻、恐怖
- 11–14：动作、战争史诗、西部、音乐
- 15–17：动画、纪录、实验
- 结尾：混合模板

## 1. 悬疑 / 推理

- **核心问题**：真相是什么，谁的解释可信？
- **信息规则**：线索可见但意义延迟；观众/人物知识差必须可追踪。
- **事件生成器**：异常、互斥证词、规则破例、错误解释、代价性验证。
- **情绪**：好奇、怀疑、焦虑、认知快感。
- **样本**：《后窗》《迷魂记》《杀人回忆》《一次别离》《唐人街探案》。
- **IP转译**：调查真实问题、测试传言、家庭秘密任务。
- **失败**：关键答案依赖从未出现的信息。

## 2. 惊悚

- **核心问题**：人物能否在威胁升级前保住目标或身份？
- **信息规则**：时间、追踪、资源减少和不可逆代价。
- **事件生成器**：被发现、倒计时、封锁、盟友不可信、选择更坏方案。
- **情绪**：警觉、失控、短暂缓解。
- **样本**：《精神病患者》《沉默的羔羊》《寄生虫》《逃出绝命镇》。
- **失败**：只有快速剪辑，没有明确威胁与代价。

## 3. 犯罪 / 黑帮 / 权力

- **核心问题**：谁制定规则，人物愿为权力付什么代价？
- **信息规则**：公开秩序与地下秩序并存。
- **事件生成器**：谈判、交换、背叛、证明忠诚、合法性争夺。
- **样本**：《教父》《无间道》《让子弹飞》《上帝之城》。
- **IP转译**：职场、家庭资源分配、团队规则，而非模仿暴力外观。
- **失败**：把狠话当权力，人物没有资源和选择。

## 4. 喜剧

- **核心问题**：人物如何在认知、身份或能力错位中保住目标？
- **信息规则**：建立预期，再以人物逻辑打破；观众常比人物多知道一步。
- **事件生成器**：误读、升级承诺、地位翻转、规则过度执行、搭档主从交换。
- **情绪**：期待、尴尬、优越/共情、释放。
- **样本**：《城市之光》《热情似火》《玩乐时间》《功夫》《土拨鼠之日》。
- **失败**：角色只是段子嘴，笑料不改变处境。

## 5. 爱情

- **核心问题**：两人能否看见、选择并承受彼此？
- **信息规则**：吸引、误读、暴露、边界和不可兼得的选择。
- **事件生成器**：共同任务、价值冲突、错误时机、公共/私人身份、牺牲。
- **样本**：《花样年华》《爱在黎明破晓前》《燃烧女子的肖像》《瑟堡的雨伞》。
- **失败**：用外貌和配乐代替双方具体选择。

## 6. 家庭 / 社会剧情

- **核心问题**：人在制度、代际与亲密义务中如何生活？
- **信息规则**：宏观问题通过具体日常、资源和选择显形。
- **事件生成器**：照护、金钱、住房、工作、教育、送别、沉默。
- **样本**：《东京物语》《一一》《偷自行车的人》《一次别离》《我是布莱克》。
- **来源启发**：[BFI Ken Loach访谈](https://www.bfi.org.uk/interviews/ken-loach-interview-sorry-we-missed-you)强调用具体生活呈现生存选择。
- **失败**：人物只代表议题，没有矛盾欲望。

## 7. 成长 / 青春

- **核心问题**：主角会接受、拒绝还是重写成人世界的规则？
- **信息规则**：第一次、边界试探、导师失效、自我命名。
- **事件生成器**：新群体、秘密、失败、离家、身体/身份变化。
- **样本**：《四百击》《月光男孩》《伯德小姐》《阳光普照》。
- **失败**：把年龄变化误当人物成长。

## 8. 科幻

- **核心问题**：一条新规则如何迫使人物重新定义人、人性或现实？
- **信息规则**：先建立可理解规则，再测试边界与代价。
- **事件生成器**：规则首次显现、滥用、悖论、制度反应、伦理选择。
- **样本**：《2001太空漫游》《潜行者》《银翼杀手》《降临》《她》。
- **IP转译**：用“如果每天只能说一句真话”等低特效思想实验。
- **失败**：设定只提供外观，不改变人物选择。

## 9. 奇幻 / 神话

- **核心问题**：人物如何在象征性规则和现实需要之间成长？
- **信息规则**：魔法有边界、代价和道德含义。
- **事件生成器**：门槛、契约、变形、试炼、归来。
- **样本**：《千与千寻》《潘神的迷宫》《指环王》《卧虎藏龙》。
- **失败**：世界观名词比人物行动多。

## 10. 恐怖

- **核心问题**：我们害怕的东西是什么，它逼人物承认什么？
- **信息规则**：安全规则逐步失效；显露与遮蔽有明确节奏。
- **事件生成器**：异常重复、污染、隔离、规则测试、身体/身份侵入。
- **样本**：《闪灵》《午夜凶铃》《逃出绝命镇》《哭声》。
- **IP转译**：用声音、缺席、日常规则异常，不必出现怪物。
- **来源启发**：[DGA恐怖导演讨论](https://www.dga.org/Craft/DGAQ/Issues/1804-Fall-2018/Horror)强调开场要建立“会遭遇何种恐惧”的承诺。
- **失败**：跳吓没有后果，威胁规则随意变化。

## 11. 动作 / 冒险

- **核心问题**：人物为什么必须从A到B，沿途失去或学会什么？
- **信息规则**：目标、地理、资源和危险必须清晰。
- **事件生成器**：路径封锁、资源耗尽、角色分工、动作选择暴露性格。
- **样本**：《七武士》《警察故事》《疯狂的麦克斯：狂暴之路》《突袭》。
- **来源启发**：[DGA动作片讨论](https://www.dga.org/craft/dgaq/issues/0703-fall-2007/thrill-rides-action-films)与乔治·米勒的“视觉句子”方法。
- **失败**：动作可任意替换，空间不清。

## 12. 战争 / 历史 / 史诗

- **核心问题**：个人选择如何被更大权力、历史和群体放大？
- **信息规则**：阵营、地理、时间和后果需清楚；宏大与私人互相解释。
- **事件生成器**：命令、忠诚冲突、资源、群体运动、历史转折。
- **样本**：《阿拉伯的劳伦斯》《现代启示录》《乱》《阿尔及尔之战》《活着》。
- **来源启发**：[ASC《乱》](https://theasc.com/articles/japanese-method-for-ran-kurosawa)展示预先清晰视觉化与多机位协作。
- **失败**：宏大场面与人物选择无关。

## 13. 西部 / 边疆

- **核心问题**：在旧秩序崩塌、新秩序未立时，谁有权制定规则？
- **事件生成器**：进入陌生地、争夺资源、公开决斗、社区选择、离开。
- **样本**：《搜索者》《西部往事》《不可饶恕》《让子弹飞》作为文化混合变体。
- **IP转译**：创业、迁居、新行业和社区规则。
- **失败**：只剩服装、风沙和对峙构图。

## 14. 音乐 / 歌舞

- **核心问题**：语言无法承载的欲望何时通过音乐与身体显形？
- **信息规则**：音乐段落必须改变关系、决定或时间。
- **事件生成器**：排练、表演、二重唱、节奏冲突、舞台/生活反差。
- **样本**：《雨中曲》《瑟堡的雨伞》《爵士春秋》《爱乐之城》。
- **来源启发**：[DGA电影歌舞](https://www.dga.org/craft/dgaq/issues/2002-spring-2020/movie-musicals)把音乐视为内在思想的表达，摄影跟随身体行动。
- **失败**：歌曲只是可删除插曲。

## 15. 动画

- **核心问题**：媒介自由如何让人物内在或世界规则可见？
- **事件生成器**：形变、视觉隐喻、尺度变化、世界规则测试。
- **样本**：《玩具总动员》《千与千寻》《蜘蛛侠：平行宇宙》《机器人总动员》。
- **来源启发**：[Pixar in a Box](https://www.pixar.com/pixar-in-a-box)把世界与人物作为可教、可练习的故事问题。
- **失败**：用视觉新奇替代因果。

## 16. 纪录 / 真人现实

- **核心问题**：现实人物正在做什么选择，我们为何要持续观察？
- **信息规则**：事实、未知结果、拍摄者位置和重演必须透明。
- **事件生成器**：任务、等待、制度摩擦、关系变化、素材中反复出现的矛盾。
- **样本**：《持摄影机的人》《浩劫》《杀戮演绎》《人生七年》。
- **来源启发**：[BFI纪录片人物](https://www.bfi.org.uk/sight-and-sound/how-create-documentary-character)与[纪录片剪辑](https://www.bfi.org.uk/features/praise-undersung-art-documentary-editing)。
- **失败**：为了完整弧线伪造事实，或把拍摄对象降成议题工具。

## 17. 实验 / 慢电影

- **核心问题**：观看时间、重复和形式本身能让观众发现什么？
- **事件生成器**：日常重复中的微差、持续观察、节奏断裂、形式规则改变。
- **样本**：《让娜·迪尔曼》《好工作》《樱桃的滋味》《持摄影机的人》。
- **IP转译**：固定机位的长期观察、相同动作跨月对照。
- **失败**：把缓慢当深刻，没有可观察变化。

## 混合模板

| 主发动机 | 辅发动机 | 分工示例 |
|---|---|---|
| 家庭 | 喜剧 | 家庭目标与代价负责内核；错位与地位交换负责释放 |
| 纪录 | 悬疑 | 现实任务负责真实性；未知结果和证据负责追更 |
| 科幻 | 爱情 | 新规则测试关系；关系选择证明规则的代价 |
| 犯罪/权力 | 喜剧 | 资源与合法性负责冲突；语言和身份错位负责节奏 |
| 恐怖 | 社会剧情 | 威胁把结构性恐惧具体化；人物生活提供代价 |
