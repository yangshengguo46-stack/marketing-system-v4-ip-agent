# 美术世界机制

## 空间角色卡

- 谁拥有/维护空间；
- 谁能进入或被排除；
- 角色在此处做什么重复动作；
- 何物最昂贵、最旧、最私密；
- 空间如何发声、反光和限制摄影；
- 本季发生何种可见变化。

## 道具

功能层级：

1. 实用：人物必须使用；
2. 信息：揭示身份、历史或规则；
3. 关系：递、夺、藏、修、丢；
4. 母题：意义随故事变化。

不要靠无功能“象征物”解释主题。

## 服装

记录人物自己想呈现什么、现实资源允许什么、工作/家庭要求什么、何时主动改变。服装连续性同时服务时间、动作和人物弧。

## 权威参考

Academy的制作设计资料强调环境和陈设能像对白/行动一样揭示人物，设计需与导演、摄影协作；再美的空间若不服务故事也无意义。[Academy production design guide](https://www.oscars.org/sites/oscars/files/complete_art_direction_activities_guide.pdf)

张艺谋《影》的二元主题通过美术、服装、摄影和表演统一执行：[ASC](https://theasc.com/articles/dual-nature-shadow)。

## 个人IP

- 固定拍摄角可建立熟悉世界；
- 真实工作痕迹优先于购买装饰；
- 让空间随长期目标变化；
- 品牌色只占可控面积，不污染肤色；
- 保护家庭地址、证件、学校和贵重物品等隐私。
