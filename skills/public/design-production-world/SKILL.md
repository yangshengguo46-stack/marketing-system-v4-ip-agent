# 美术与世界视觉化

设计可被人物使用的生活世界，不设计与行动无关的漂亮背景。

## 工作流

1. 从人物、时代、资源和日常行为研究现实；
2. 写世界规则与社会层级；
3. 为每个主要空间定义功能、所有权和变化；
4. 让道具承担行动、记忆或证据；
5. 让服装表达角色选择而非标签；
6. 协调摄影机、光线、声音和竖屏构图；
7. 建可重复拍摄和逐季演化计划。

查阅 `references/production-world.md`。

## 输出

- 世界视觉命题；
- 空间与角色关系图；
- 主场景清单；
- 英雄道具及戏剧功能；
- 服装/材质/颜色逻辑；
- 时代与职业研究项；
- 摄影、声音协同；
- 手机IP低成本复用方案。

美术细节若不会被人物看见、触碰、避开、争夺或改变，先判断是否值得制作。
