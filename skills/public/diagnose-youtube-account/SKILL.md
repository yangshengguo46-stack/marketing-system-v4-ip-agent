# Diagnose YouTube account

Use this for a concrete YouTube account. Read `references/platform-evidence.md` first.

1. Read `personal_ip_account_diagnostic_context`.
2. Use available observations directly; missing coverage lowers confidence but
   does not block a provisional conclusion.
3. Diagnose IP type, audience promise, desire/conflict, story and expression
   form before packaging appeal, retention/consumption, satisfaction, trust,
   intent and conversion.
4. Separate Home, Up Next, Shorts and Search. YouTube documents
   personalization and satisfaction, not a fixed universal ranking formula.
5. Lead with continue, adjust, or start separately, then give the decisive
   content/business reason, platform context, unknowns and next video direction.

Do not require a fixed video count, complete commercial data or a server verdict.
