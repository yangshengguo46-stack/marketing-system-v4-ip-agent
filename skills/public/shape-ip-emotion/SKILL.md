# 个人IP情绪导演

情绪是人物与观众对欲望重要性、实现距离、变化速度、控制感、归因和不可逆性的体验，不是镜头元素的固定含义。先读取欲望—行为映射，再用层级、转变和可观察证据设计情绪。

## 六层情绪系统

1. **账号层**：观众长期回来寻找的情绪承诺。
2. **季度层**：一段时期的主导压力、转向与兑现。
3. **小弧层**：数条内容组成一次期待—受阻—改变。
4. **单集层**：入场情绪、峰值、释放和离场余味。
5. **场景层**：人物的情绪策略如何因阻力而变化。
6. **镜头层**：信息距离、空间控制、运动、光色、声音和剪辑共同调节体验。

## 设计步骤

1. 标出每个节拍的欲望对象、当前策略、实现距离和控制感。
2. 先定义离场情绪，再逆推路径。
3. 把情绪写成转变：好奇→怀疑、期待→尴尬、控制→失控，而非一个孤立名词。
4. 标注效价、唤醒度和控制感，但不要把三轴当成完整心理诊断。
5. 指定触发情绪的叙事事实、人物行动和欲望状态变化。
6. 为每个镜头元素写“关系性理由”。
7. 用观众复述、表情/语义反馈、看完率与延迟评论交叉验证。

## 单集情绪曲线

```markdown
| 节拍 | 欲望/实现距离 | 观众已知 | 人物行动 | 目标情绪 | 唤醒度 | 控制感 | 视听手段 | 转向证据 |
```

至少包括：

- 入场：快速建立情境与缺口；
- 加压：阻力升级或信息不对称；
- 转向：新事实迫使重新解释；
- 峰值：人物付出代价或作出选择；
- 释放：笑、答案、行动完成或情绪承认；
- 余味：留下人物微变化或长期问题。

## 镜头情绪规则

查阅 `references/emotion-and-shot-language.md`。

- 近景增加面部信息的机会，不保证亲密；威胁的脸也可能增强压迫。
- 广角和长焦改变空间关系，但意义取决于机位、距离和阻挡。
- 色彩联想受文化、饱和度、明度、邻色和情境影响，先建立片内规则。
- 剪辑会重新解释同一表情；库里肖夫效应是语境偏置，不是万能按钮。
- 声音可以先于画面建立危险、缺席或期待，不能永远用配乐替代人物行动。

## 输出

1. 账号情绪承诺及禁区；
2. 季度情绪波形；
3. 核心情绪调色盘：常用、稀缺、保留；
4. 单集曲线；
5. 场景策略变化；
6. 镜头与声音方案；
7. 失败条件与验证办法。
