# 喜剧机制

## 六个发动机

1. **认知错位**：人物对规则/关系的解释与现实不同；
2. **地位交换**：以为掌控者暴露无知，低位者掌握关键能力；
3. **规则过度执行**：合理规则被人物执行到荒谬后果；
4. **升级承诺**：为掩盖小错，不断承担更大代价；
5. **身体与空间**：目标被物理条件具体阻碍；
6. **语言行动**：试探、抬价、遮掩在字面与真实目的间错位。

## 笑点节拍

建立规则 → 让观众形成预测 → 偏离但保持人物逻辑 → 后果升级 → 最后一次地位/意义翻转 → 关系余味。

## 搭档

每个节拍标：

- 谁掌握地位；
- 谁掌握信息；
- 谁掌握能力；
- 谁在领观众解释；
- 下一拍哪项交换。

[BFI《城市之光》](https://www.bfi.org.uk/film/18e7950b-fa7e-5a5e-a897-a782a40f1c5c/city-lights)展示视觉笑料、边缘人物同情与哀感共存。

## 讽刺

- 明确攻击结构、规则或自欺，不默认攻击弱者；
- 让被讽刺立场具有真实诱惑；
- 由后果暴露矛盾，不只由旁白宣布；
- 真人IP避免长期固定一个家人为无能/贪婪/丑角；
- 黑色喜剧仍需标明现实伤害边界。
