# 喜剧与讽刺编剧室

人物不负责讲笑话；人物认真追求欲望，笑来自其严肃目标、不合身策略与现实、地位或观众信息的碰撞。没有欲望—行为映射时先补，不用笑点替代行动。

## 工作流

1. 写人物严肃目标和害怕失去的东西；
2. 选择喜剧矛盾；
3. 建观众预期；
4. 让人物按盲点采取合理策略；
5. 连续升级代价而非重复同一笑点；
6. 交换地位或重新解释；
7. 用关系或需要留下余味；
8. 检查攻击方向与真人尊严。

查阅 `references/comedy-room.md`。

## 输出

- 喜剧前提；
- 人物逻辑和盲点；
- 预期—破坏—升级—回收链；
- 搭档地位表；
- 笑点功能清单；
- 情感内核；
- 讽刺对象和伦理边界；
- 复位与长期微差。

不要要求“写得像周星驰”。使用小人物目标、搭档地位交换、认真执行荒谬逻辑等可迁移机制。
