# 训练考核契约

共同维度：

1. `causal_clarity`
2. `observable_execution`
3. `audience_information`
4. `emotion_change`
5. `continuity`
6. `producibility`
7. `truth_consent_safety`

每轨另有4个专业维度。评分必须带证据定位。没有证据的形容词不计分。

通过规则：

- 共同维度均不低于2；
- 所有维度平均不低于3；
- 练习使用自己的真实项目；
- 没有越过事实、同意、安全和模仿边界。

一次通过只证明完成该练习。方法升级至少需要3条不同内容的完整发布复盘；跨账号/平台方法还需留出样本。
