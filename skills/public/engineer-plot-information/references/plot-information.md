# 情节与信息工具

## 因果节点

每个节点写：

`条件 → 人物目标 → 选择/行动 → 即时结果 → 新限制 → 后续债务`

若结果可由任意行动触发，因果弱；若转折需要未出现人物或规则，属于作者干预。

## 信息位置

| 状态 | 主要体验 | 适用 |
|---|---|---|
| 观众先知道 | 悬念、尴尬、期待 | 危险逼近、喜剧失败 |
| 人物先知道 | 好奇、观察遮掩 | 秘密、潜伏、身份 |
| 同步知道 | 发现、冲击、共同行动 | 调查、任务 |
| 双方都误解 | 重解释 | 反转、关系冲突 |

希区柯克通过观众知道危险来区分悬念与突然惊讶；《迷魂记》提前揭示部分真相以延长悬念。[ASC](https://theasc.com/articles/flashback-vertigo)

## 公平误导

- 线索真实，解释错误；
- 关键事实出现过，但注意力被人物目标合理转移；
- 嫌疑人有独立动机，不只是红鲱鱼；
- 回看时能指出证据，不靠新规则；
- 误导不篡改已呈现的客观画面。

## 转折强度

- 一级：新信息改变局部策略；
- 二级：改变目标或盟友；
- 三级：重写此前意义或人物身份；
- 四级：改变故事规则/世界理解。

短视频通常一个主转折足够。频繁三级转折会透支可信度。

## 伏笔账本

记录ID、首次出现、表层解释、真实功能、观众注意度、强化次数、回收窗口和放弃处理。暗线证据若无法进入账本，说明尚未进入作品。
