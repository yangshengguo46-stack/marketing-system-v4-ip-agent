# 欲望—行为协议

## 1. 证据边界

可核实的公开材料支持以下范围：

- 查理的公开课程条目把欲望与共情列为故事灵感来源；公开答疑单独讨论人物的 `want` 与 `need`。
- “连猴子都懂”的表述可在第三方课程笔记中检索到；未取得对应原始课段时，只把它作为转述，不冒充逐字原话。
- Céline Sciamma在BAFTA编剧演讲中把写作描述为“多重欲望的建筑”，并把场景视为欲望单元；她同时质疑把冲突当作唯一叙事动力。
- Tony Gilroy在BAFTA编剧演讲中把对人类行为的理解视为编剧能力的关键上限。
- BBC剧本格式指南要求场景动作只写银幕上正在发生的内容。

## 2. 六层欲望梯

| 层 | 问题 | 常见错误 |
|---|---|---|
| 底层驱力 | 为什么这件事对他有根本意义？ | 把分析推断冒充真人自述 |
| 意识欲望 | 他自己会说想要、保住、逃离什么？ | 写成“成为更好的自己” |
| 具体目标 | 到什么条件可以判断成功或失败？ | 没有对象、期限或触发 |
| 当前策略 | 他正在改变谁、什么或哪条规则？ | 用情绪形容词代替动作 |
| 有代价选择 | 哪两样东西不能兼得？ | 只有困难，没有选择 |
| 状态改变 | 结果改变了什么现实状态？ | 视频结束但局势没变 |

`need`不得自动写成作者给人物安排的道德答案。它可以是尚未意识到的需要、矛盾欲望或长期适应问题，必须保留证据等级。

## 5. 反作用场

反作用不等于必须安排恶人。

| 类型 | 示例 | 结构作用 |
|---|---|---|
| 对立欲望 | 一人要公开，另一人要隐瞒 | 产生谈判与冲突 |
| 内在反欲望 | 想成功又怕被看见 | 产生接近—退缩 |
| 时间/资源 | 截止期、预算、体力 | 迫使取舍 |
| 信息 | 想知道但证据不足 | 产生调查、等待、误读 |
| 制度/规则 | 合同、家庭规则、平台限制 | 产生绕行、抗争、适应 |
| 互惠欲望 | 两人都想靠近但节奏不同 | 产生观看、回应与延迟 |
| 环境/身体 | 距离、天气、伤病、空间 | 使动作具体化 |

## 6. 起承转合的行为解释

- 起：缺口被触发，人物选定目标。
- 承：人物行动，反馈迫使其重复、升级或换策略。
- 转：新信息、失败或代价使原策略失效，人物必须选择。
- 合：目标实现、失败、放弃或被重新理解，现实状态改变。

转折至少改变目标、策略、风险、关系、信息或意义之一。偶然事件只有在迫使人物选择时才成为有效转折。

## 7. 情绪是欲望状态

以下是设计启发，不是固定心理诊断：

| 欲望状态 | 常见目标体验 |
|---|---|
| 重要且有实现可能 | 希望、期待 |
| 结果不确定且时间收紧 | 紧张、焦虑 |
| 被可归责对象阻挡 | 愤怒 |
| 已拥有之物受到威胁 | 恐惧 |
| 欲望或失败暴露身份 | 羞耻、尴尬 |
| 目标不可逆失去 | 悲伤 |
| 威胁解除 | 释然 |
| 严肃欲望遇到错误认知或不合身策略 | 喜剧 |
| 想知道而信息被控制 | 好奇、悬疑 |

设计情绪时同时看：重要性、距离、变化速度、控制感、归因和不可逆性。

## 8. 类型是欲望的变形场

- 悬疑：知道真相的欲望面对信息控制。
- 喜剧：严肃欲望面对盲点、错位或不合身策略。
- 爱情/家庭：靠近、照护与自主的欲望互相牵制。
- 恐怖：生存、身体或身份边界面对入侵。
- 犯罪/权谋：资源、地位与合法性欲望进入多方博弈。
- 科幻/奇幻：古老欲望进入新的世界规则。
- 动作/冒险：目标被地理、时间、资源和身体后果具体化。
- 纪录/真人：现实欲望在不可预写的结果中留下证据。

## 9. 六尺度继承

| 尺度 | 欲望单位 |
|---|---|
| 账号生命周期 | 身份或生活状态的长期改变 |
| 季 | 当前可观察里程碑 |
| 小弧 | 一种策略的连续尝试 |
| 单集 | 当日可判断成败的目标 |
| 场景 | 此刻要从对手、环境或自己那里争取的改变 |
| 镜头 | 可见动作、反作用和结果 |

下层可以反抗上层，但不能与上层毫无关系。并非每集都要推进大目标；它也可以验证人物策略、关系欲望或失败模式。

## 10. 诊断句

- 有事件无欲望：流水账。
- 有欲望无行动：愿望或自白。
- 有行动无反作用：过程展示。
- 有阻力无策略变化：重复受挫。
- 有转折无选择：作者操纵。
- 有结果无状态改变：情节停止。
- 有人物欲望无观众欲望：可能真实，但缺少观看牵引。
- 只有原始欲望无矛盾欲望：易懂，但容易单薄。
