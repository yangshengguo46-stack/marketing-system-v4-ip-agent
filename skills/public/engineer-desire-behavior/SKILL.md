# 欲望—行为引擎

先建立人物为何行动以及行动如何改变局势，再写情节、台词、表演或镜头。只构造当前任务需要的最小行为链，不强迫用户先填写一套账本。

## 核心链

```text
缺口/触发 → 欲望 → 可检验目标 → 行动策略 → 现实反馈
         → 策略变化 → 有代价的选择 → 状态改变 → 新欲望
```

欲望本身不是故事。只有当人物为它采取行动，并被反馈迫使改变策略或选择时，才形成可拍摄的故事。

## 工作流

1. 锁定欲望主体，不用“我们”“大家”掩盖谁在行动。
2. 分开四层：
   - `root_drive`：安全、依恋、自主、地位、照护、好奇等底层驱力；证据不足时写 `unknown`。
   - `conscious_want`：人物自己能表达的想要或逃避。
   - `goal`：在具体期限或触发条件下可判断成败的目标。
   - `tactic`：此刻为了改变人、物、关系或规则而采取的动作。
3. 找反作用场：
   - 另一个人的相反欲望；
   - 同一人物不能兼得的第二欲望；
   - 时间、信息、制度、身体、资源或世界规则；
   - 互相靠近、等待、观看或回应造成的变化，不强迫所有故事都有反派。
4. 把心理词改成动作动词：争取、隐瞒、试探、拖延、交换、修复、逃离、保护、揭露。
5. 写策略变化。重复同一动作只算升级，不自动构成转折。
6. 写有代价的选择和状态差值。结尾至少改变关系、身份、能力、信息、资源或世界规则之一。
7. 写观众欲望：观众为什么想继续确认结果、真相或选择。
8. 运行静音行为测试；不通过就回到目标和行动，不用旁白补洞。

详细字段、层级映射、情绪/类型转译与证据边界见 `references/desire-behavior-protocol.md`。

## 按当前尺度工作

### 长期系列

回答这个IP长期追更的发动机：

- 主体持续想得到、保住、摆脱、隐藏或证明什么；
- 成功和失败分别是什么可观察状态；
- 哪些反欲望可以持续生成事件；
- 用什么现实证据记录进度；
- 哪些伦理边界不能为了冲突跨越。

### 单集或场景

每集冻结：

- 主体、意识欲望和当集目标；
- 触发条件、反作用、得失；
- 策略序列和可拍行动；
- 有代价的选择、状态改变；
- 观众欲望与静音测试。

## “猴子测试”的使用边界

把它当作前语言因果可见性测试，不当作生物学定律：

- 静音去字幕后，能否看出谁想要什么；
- 能否看出他正在采取什么行动；
- 能否看出反作用和失败后果；
- 能否看出结尾状态已改变。

它只验证“看得懂”，不验证主题深度、伦理复杂性、潜台词或审美价值。原始欲望负责入场，矛盾欲望和代价负责留下。

## 交给创作

把必要的欲望、目标、阻力、策略变化、代价、状态差值和观众问题直接融入当前脚本或场景。用户只要脚本时，不先展示内部分析表；只有用户要求诊断时才展开行为链。

不得替真人宣称隐性欲望。未经证实的真人深层动机必须标为推断或未知；虚构人物可以拥有创作设定，但不能冒充真实案例。不得为了让故事成立制造真实冲突、羞辱或伤害。
