# 战争历史史诗编剧室

用具体人物有证据边界的欲望和选择进入宏大尺度，同时保持事实、群体与制度的复杂性。不得替历史人物断言隐性欲望。

## 工作流

1. 建事实时间线、来源等级和争议项；
2. 区分历史事实、综合、推断与虚构；
3. 选择私人视点和其信息限制；
4. 建阵营、制度、地理和资源；
5. 让历史压力进入住房、食物、工作、家庭和身体；
6. 组织群体行动与个人代价；
7. 设计跨时间后果；
8. 审查代表性、创伤和政治/法律风险。

查阅 `references/history-epic-room.md`。

## 输出

- 证据地图；
- 历史/戏剧双时间线；
- 阵营与制度图；
- 私人视点；
- 群像功能；
- 史诗尺度切换；
- 虚构与合成说明；
- 权利、创伤与事实审查。

不得把历史人物的内心、私密对话或动机直接写成事实；合成人物和戏剧重构需披露。
