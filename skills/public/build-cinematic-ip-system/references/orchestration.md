## 何时跳过

- 没有对标研究需求：跳过蒸馏。
- 用户已有可靠圣经：先审查，能用则不重做。
- 用户已有经过证据校验的欲望账本：可复用生命周期层，但每集仍要重做当集映射。
- 单人口播且无戏剧场景：表演Skill只处理目标、听众和口语任务，视觉Skill简化。
- 单一工种问题：直接调用细分Skill，不重跑全部基础层。
- 只有诊断授权：停在审片，不自动改稿。
- 只有一条紧急日更：先保单集事件和真实性，长期系统另列债务。
- 用户只要看片/研究：停在机制包，不创建真实项目。
- 未准备发布：可以做创作审片，但不伪造发布回执和指标。

## 反馈回路

发布后记录：

- 观众复述的事件；
- 观众记住的人物特征；
- 目标情绪与实际情绪；
- 承诺兑现处与划走风险；
- 对长期问题的新猜测；
- 事实/伦理反馈；
- 拍摄可执行性和成本。

反馈路由：

| 现象 | 优先返回 |
|---|---|
| 看不懂发生了什么 | 单集编剧 / 视觉导演 |
| 看懂事件但不明白人物为何这样做 | 欲望—行为引擎 / 人物关系 |
| 人物说想要但没有可见行动 | 欲望—行为引擎 / 表演指导 |
| 有很多冲突但像作者硬加 | 欲望—行为引擎 / 情节信息 |
| 记得事情但不记得人 | 剧集圣经 / 表演指导 |
| 每条都像但越来越疲劳 | 类型发动机 / 情绪系统 |
| 追更猜测多但单集不满足 | 单集编剧 / 连续性审片 |
| 画面漂亮但情绪不对 | 情绪系统，再检查表演与叙事 |
| 人物一直站着说话 | 场面调度 |
| 镜头参数很多但关系不清 | 叙事摄影 |
| 所谓滤镜每条都变 | 光色质感 |
| 剪得快却看不懂 | 情节信息 / 剪辑节奏 |
| 世界像空布景 | 美术世界 |
| 配乐一直响却无空间 | 声音设计 |
| 评论质疑造假或冒犯 | 连续性审片的真实性与伦理P0 |
| 预测经常过度乐观 | 校准闭环，检查基线、最小效应和置信度 |
| 一次爆款后想固化公式 | 继续积累至少3条完整复盘 |
| 方法换平台后失效 | 将规则降回局部范围并做留出测试 |

## 版本管理

为共享状态记录：

- `bible_version`
- `desire_protocol_version`
- `lifecycle_desire_hash`
- `genre_contract_version`
- `emotion_system_version`
- `episode_id`
- `visual_grammar_version`
- `audit_date`
- `subject_id`
- `operation_scope`
- `preflight_hash`
- `metric_window`
- `retrospective_count`
- `method_version`

发布后的真实结果写入原生新版本，不回改发布前预测。机制卡只有在不同发布回执的
多次完整复盘后才升级为有范围的主体规则；跨平台或格式仍需留出测试。
