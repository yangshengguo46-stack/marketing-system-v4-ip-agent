# 全球导演、编剧与动画创作者图谱

用途：按问题选择研究对象。下列“机制”多数是作品与专业资料的综合入口，不是创作者自称公式。

## 叙事、类型与导演

| 创作者 | 代表样本 | 研究机制 | IP转译 |
|---|---|---|---|
| Alfred Hitchcock | 《后窗》《迷魂记》《惊魂记》 | 观众信息位置、预切、主观视点、悬念/惊讶 | 先写观众知道什么再遮挡 |
| Akira Kurosawa | 《七武士》《用心棒》《乱》 | 地理清楚、群体调度、天气元素、动作因果 | 任务视频先建立路径与阵营 |
| Yasujirō Ozu | 《东京物语》《晚春》 | 日常排列、低机位、固定空间、克制变化 | 用重复仪式记录家庭微差 |
| Kenji Mizoguchi | 《雨月物语》《山椒大夫》 | 长时段调度、社会制度与人物命运 | 让空间和持续动作承担压迫 |
| Satyajit Ray | 《大地之歌》《音乐室》 | 人文观察、成长、环境细节 | 真实环境与人物需要并重 |
| Ingmar Bergman | 《假面》《婚姻生活》 | 面孔、信仰、关系对峙 | 近景需提供可读心理行动 |
| Federico Fellini | 《八部半》《甜蜜的生活》 | 自传、幻想、群像景观 | 现实与表演层需有清楚切换 |
| Agnès Varda | 《五至七时的克莱奥》《拾穗者》 | 主观时间、散文纪录、自我反思 | 拍摄者位置进入故事 |
| Robert Bresson | 《扒手》《死囚越狱》 | 动作、物件、声音与非展示性表演 | 用任务和声音代替情绪说明 |
| Andrei Tarkovsky | 《潜行者》《镜子》 | 时间、元素、记忆与精神空间 | 持续镜头必须承载变化 |
| Stanley Kubrick | 《2001》《闪灵》《巴里·林登》 | 形式控制、空间秩序、技术与人 | 视觉规则的破例对应主题转向 |
| Francis Ford Coppola | 《教父》《现代启示录》 | 家庭/权力、歌剧性结构、声音实验 | 外部组织冲突进入亲密关系 |
| Martin Scorsese | 《出租车司机》《好家伙》 | 主观叙述、欲望速度、音乐与剪辑 | 形式节奏绑定人物自我解释 |
| Steven Spielberg | 《大白鲨》《辛德勒名单》 | 视觉清晰、观众视点、奇观与人物反应 | 奇观先由人物看见并赋义 |
| David Lynch | 《蓝丝绒》《穆赫兰道》 | 梦逻辑、声音、不安的日常 | 建重复感官规则，不复制怪异符号 |
| Michael Mann | 《盗火线》《借刀杀人》 | 职业程序、城市夜、对手镜像 | 技能和工作流程成为人物 |
| Jane Campion | 《钢琴课》《犬之力》 | 欲望、权力、身体与风景 | 触觉细节和隐性策略 |
| Kathryn Bigelow | 《拆弹部队》《猎杀本·拉登》 | 程序、身体风险、道德不确定 | 任务选择暴露人物依赖 |
| Claire Denis | 《好工作》《白色物质》 | 身体、殖民历史、碎片与音乐 | 身体动作承担未言关系 |
| Céline Sciamma | 《燃烧女子的肖像》 | 凝视、互相观看、艺术劳动 | 让观看关系成为行动与伦理 |
| Asghar Farhadi | 《一次别离》《推销员》 | 道德因果、信息差、每方有理 | 反转由行为后果而非新规则 |
| Abbas Kiarostami | 《特写》《樱桃的滋味》 | 现实/表演边界、道路、开放结局 | 真人内容公开拍摄关系 |
| Nuri Bilge Ceylan | 《冬眠》《远方》 | 长对话、风景、道德自欺 | 台词行动与空间距离并用 |
| Bong Joon-ho | 《杀人回忆》《寄生虫》 | 类型混合、空间阶级、情绪转档 | 辅类型围绕同一人物选择 |
| Park Chan-wook | 《老男孩》《小姐》《分手的决心》 | 主观信息、欲望、精密视听转场 | 形式转场必须改写关系 |
| Hirokazu Kore-eda | 《步履不停》《小偷家族》 | 家庭定义、日常、儿童视点 | 家庭关系由照护行为证明 |
| Hayao Miyazaki | 《千与千寻》《幽灵公主》 | 世界生态、成长、劳动与矛盾反派 | 规则通过劳动和选择展示 |
| Mamoru Hosoda | 《穿越时空的少女》《狼的孩子雨和雪》 | 家庭、数字世界、成长时间 | 幻想规则进入日常照护 |
| Isao Takahata | 《萤火虫之墓》《辉夜姬物语》 | 日常悲剧、媒介风格与情绪距离 | 形式改变需服务人物经验 |
| George Miller | 《疯狂的麦克斯：狂暴之路》 | 视觉句子、中心地理、动作因果 | 单镜头服从路径和流动 |
| Ridley Scott | 《异形》《银翼杀手》 | 世界质感、环境、类型视觉 | 环境先拥有功能和声音 |
| James Cameron | 《异形2》《终结者2》《泰坦尼克号》 | 清楚目标、技术流程、升级与情感回收 | 复杂制作仍以因果清晰为先 |
| Guillermo del Toro | 《潘神的迷宫》《水形物语》 | 怪物伦理、童话与历史、材质 | 奇幻生物承载道德视角 |
| Alfonso Cuarón | 《人类之子》《罗马》 | 长时段观察、前后景、历史与家庭 | 让多层行动在主镜头中并存 |
| Alejandro G. Iñárritu | 《鸟人》《荒野猎人》 | 连续性幻觉、身体与主观压力 | 形式连续需对应人物困境 |
| Denis Villeneuve | 《降临》《边境杀手》《沙丘》 | 情绪命题、尺度、声音与信息 | 先定义“人感到什么”再设计世界 |
| Christopher Nolan | 《记忆碎片》《致命魔术》《敦刻尔克》 | 时间结构、规则、平行压力 | 复杂结构需有清楚情绪锚 |
| David Fincher | 《七宗罪》《社交网络》《消失的爱人》 | 行为精度、控制性视点、信息与程序 | 机位规则服务人物控制关系 |
| Jordan Peele | 《逃出绝命镇》《不》 | 类型隐喻、观众状态、线索与二刷 | 演员知道观众当前信息 |
| Greta Gerwig | 《伯德小姐》《小妇人》 | 成长、时间并置、关系细节 | 长线转变由多次小选择累计 |
| Sofia Coppola | 《迷失东京》《绝代艳后》 | 主观孤独、环境表面与内心差异 | 空间与生活节奏表达错位 |
| Kelly Reichardt | 《温蒂和露西》《第一头牛》 | 资源、劳动、微小选择 | 小预算从具体生存条件生戏 |
| Lucrecia Martel | 《沼泽》《扎马》 | 画外声音、身体、社会空间 | 声音先建立不可见权力 |
| Céline Song | 《过往人生》 | 时间、未选择的人生、克制关系 | 余味来自不能同时拥有 |
| Damien Chazelle | 《爆裂鼓手》《爱乐之城》 | 音乐节奏、野心、关系代价 | 表演段落改变人物地位 |
| Jacques Tati | 《玩乐时间》 | 空间喜剧、群体注意、声音笑点 | 竖屏慎用，需重新安排注意入口 |
| Charlie Chaplin | 《城市之光》《摩登时代》 | 小人物、视觉动作、哀感 | 身体障碍服务尊严目标 |
| Billy Wilder | 《热情似火》《日落大道》《公寓春光》 | 结构、身份错位、讽刺与情感 | 喜剧伪装迫使道德选择 |
| Nora Ephron | 《当哈利遇到莎莉》 | 关系对话、时间、都市观察 | 对白争论背后有真实关系目标 |
| Charlie Kaufman | 《成为约翰·马尔科维奇》《暖暖内含光》 | 自反结构、身份、记忆与复杂性 | 形式化设定服务无法简化的内心问题 |
| Tony Gilroy | 《迈克尔·克莱顿》《安多》 | 行为、程序、制度与道德选择 | 让人物通过专业动作显露价值 |
| Aaron Sorkin | 《社交网络》《史蒂夫·乔布斯》 | 快速论辩、目标驱动场景 | 不仿语言；研究论点与行动对齐 |
| Phoebe Waller-Bridge | 《伦敦生活》 | 观众共谋、羞耻、喜剧与破墙 | 直接对镜需改变观众/人物关系 |

## 动画工作室与集体

| 集体 | 研究方向 |
|---|---|
| Pixar | 世界—人物—选择、清晰情绪命题、迭代故事板 |
| Studio Ghibli | 劳动、生态、成长、生活细节与世界规则 |
| Laika | 材质、定格限制、恐怖与成长 |
| Cartoon Saloon | 地方视觉传统、神话、家庭与平面设计 |
| Sony Animation / Spider-Verse团队 | 多视觉体系对应多世界/人物，漫画语法参与叙事 |
