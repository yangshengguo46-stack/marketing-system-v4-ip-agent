# 全球影片案例索引：17类题材

不是排行榜。样本交叉参考 [BFI Sight and Sound](https://www.bfi.org.uk/sight-and-sound/greatest-films-all-time)、[WGA 101](https://www.wga.org/writers-room/101-best-lists/101-greatest-screenplays/list)、[ASC 100](https://theasc.com/news/asc-unveils-list-of-100-milestone-films-in-cinematography-of-the-20th-century)及各国电影传统。每次只选与当前问题有关的3–6部。

## 导航

1. 悬疑/推理、惊悚、犯罪/权力
2. 喜剧、爱情、家庭/社会、成长
3. 科幻、奇幻、恐怖、动作
4. 战争/历史/史诗、西部、音乐
5. 动画、纪录、实验/慢电影
6. 选样规则

## 选样规则

1. 一部经典范式；
2. 一部现代重构；
3. 一部非好莱坞变体；
4. 一部制作规模接近用户的作品；
5. 必要时增加女性创作者、动画或纪录样本；
6. 只提取与当前创作问题直接相关的机制。
