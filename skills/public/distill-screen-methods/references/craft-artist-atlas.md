# 摄影、剪辑、声音、美术与表演工种图谱

图谱用于选择研究路径，不把工种简化成“滤镜风格”。

## 表演与动作

| 传统/创作者 | 研究机制 | 转译边界 |
|---|---|---|
| Stanislavski体系 | 规定情境、目标、行动、注意与真实体验 | 不把“情绪记忆”当唯一方法 |
| Meisner训练 | 倾听、当下反应、重复与行为真实性 | 镜头/现场安全仍需导演管理 |
| Stella Adler | 想象、文本、社会与规模 | 不用私人创伤代替想象 |
| Michael Chekhov | 心理姿态、想象身体、氛围 | 防止动作符号化 |
| Laban efforts | 时间、重量、空间、流动的身体选择 | 用于动作差异，不诊断人格 |
| Practical Aesthetics | 字面行动、核心行动、仿佛 | 作为行动分析，不作为唯一真理 |
| Jacques Lecoq传统 | 身体、空间、面具、喜剧与节奏 | 适配镜头尺度 |
| 成龙动作团队 | 道具、空间、身体喜剧和因果 | 真人IP不复制危险 |

机构入口：[RSC rehearsal approaches](https://www.rsc.org.uk/learn/schools-and-teachers/teacher-resources/rehearsal-room-approaches-to-shakespeare)；[National Theatre Laban](https://shop.nationaltheatre.org.uk/products/labans-efforts-in-action)；[BAFTA Samantha Morton](https://www.bafta.org/media-centre/press-releases/bafta-masterclass-acting-with-samantha-morton/)。
