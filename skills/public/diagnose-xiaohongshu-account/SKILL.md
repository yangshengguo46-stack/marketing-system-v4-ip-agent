# Diagnose Xiaohongshu account

Use this for a concrete Xiaohongshu account. Read
`references/platform-evidence.md` first.

1. Read `personal_ip_account_diagnostic_context`.
2. Treat data coverage as context, never as permission to diagnose.
3. Diagnose IP type, audience promise, desire/conflict, story and expression
   form before title/cover consistency, consumption, save/share/search value,
   trust, intent and conversion.
4. Inspect recommendation eligibility, search fit, originality and traffic
   sources separately. Do not invent current weights or infer a shadowban from reach.
5. Give a direct continue, adjust, or start-separately recommendation with the
   decisive reason, evidence, uncertainty and next concrete note/video.

No fixed publication count or complete funnel dataset is required.
