# 悬疑、推理与惊悚

## 三种主合同

- **谜题型**：观众想知道答案，公平线索与推理满足优先；
- **悬念型**：观众知道风险，等待人物发现或躲过；
- **惊悚型**：威胁、时间、资源和不可逆代价推动行动。

## 线索卡

- 客观事实；
- 首次出现方式；
- 表层解释；
- 真实解释；
- 谁注意到；
- 何时验证；
- 回看是否公平。

## 嫌疑结构

每个候选解释都需：

- 机会/条件；
- 可理解动机；
- 支持证据；
- 反证或矛盾；
- 与主题/人物关系；
- 被排除的可见行动。

不要让候选只为凑数。

## 节拍

异常 → 初始解释 → 验证失败 → 新候选 → 代价升级 → 关键线索重读 → 揭示 → 人物选择/余波。

希区柯克通过提前给观众部分危险制造悬念；《迷魂记》中提前揭示也让悬念延长。[ASC](https://theasc.com/articles/flashback-vertigo)

乔丹·皮尔强调恐怖和喜剧都要精确追踪观众当前知道什么，并让演员据此保护线索和揭示：[DGA](https://www.dga.org/craft/dgaq/issues/1704-fall-2017/gen-next-jordan-peele)。

## 个人IP

- 事实核查、骗局、生活谜题和实验验证适合单元结构；
- 每集先给答案，长期线只留一次证据；
- 不为了悬疑隐瞒会影响观众安全的关键信息；
- 真人指控必须有证据、合法性和隐私审查。
