# 悬疑推理惊悚编剧室

悬疑让观众形成问题并参与解释；惊悚让人物在威胁与时间压力下行动。先读取欲望—行为映射：调查者想知道什么、谁想隐瞒什么、观众想确认什么。两者可混用，但合同不同。

## 工作流

1. 写真相时间线和核心问题；
2. 定义调查者的能力、盲点与代价；
3. 建嫌疑/解释矩阵；
4. 把线索设计成可见事实与可错解释；
5. 决定观众相对人物的信息位置；
6. 用验证行动而非解释台词推进；
7. 设计揭示后的人物选择；
8. 审查公平性与二刷可读性。

查阅 `references/mystery-thriller-room.md`。

## 输出

- 类型合同；
- 真相与观众呈现双时间线；
- 线索/误导/嫌疑矩阵；
- 威胁和时间压力；
- 调查节拍；
- 揭示、代价与余波；
- 单元案与长期谜团配额；
- 作弊检查。

反转若只改变事实、不改变人物选择和前文意义，只是信息惊讶。
