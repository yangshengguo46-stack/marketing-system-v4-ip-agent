# 个人IP镜头表演指导

不给演员“更悲伤一点”这种不可执行指令。读取当集欲望—行为映射，把结果性情绪改写成对对手、空间或物件采取的行动。

## 准备

1. 说明人物此刻知道什么，不知道什么。
2. 从意识欲望提取可玩的目标：让对方留下、逼对方承认、隐藏恐惧、夺回主导。
3. 写阻力：对手策略、时间、身份、空间、身体或道德底线。
4. 把场景切成策略变化，而不是情绪段落。
5. 指定身体任务和焦点对象。
6. 根据景别调整幅度，但不把“近景=少演、全景=大演”当机械定律。

## 表演任务卡

```markdown
- 此刻已知：
- 意识欲望：
- 可玩的目标：
- 阻力：
- 策略序列：
- 潜台词：
- 身体任务：
- 关键听反应：
- 镜头尺度与技术限制：
- 进入状态的事实/想象：
- 连续性锚点：
- 备用版本：
```

## 导演沟通

- 一次只给一个主要调整。
- 先说行动与对象，再说速度、力度或空间限制。
- 给两个方向差异明确的take，不用十个近似take耗损真实反应。
- 喜剧先保护关系、期待与节拍，不能只要求“演得好笑”。
- 悬疑/恐怖要告诉演员观众此刻知道多少，以便线索既可见又不泄底。
- 素人优先设计真实任务、真实对象和可重复动作，少让其背长段“自然台词”。
- 拍摄顺序跳跃时，记录进入场景前发生的事实、能量水平、身体状态和道具位置。

查阅 `references/performance-methods.md`。

## 安全与伦理

- 建立可拒绝、可暂停、可替代的工作环境。
- 不以真实羞辱、恐吓、危险或隐瞒关键信息换取“真实反应”。
- 涉及创伤、亲密、儿童、身体风险时使用明确同意与专门流程。
- 真人IP的“人设”不能迫使本人长期表演与现实相冲突的身份。

## 输出

1. 场景事实与人物信息；
2. 逐节拍表演任务；
3. 镜头尺度适配；
4. 2–3个take方向；
5. 连续性记录；
6. 安全与同意检查。
