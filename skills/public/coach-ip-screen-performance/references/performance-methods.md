# 镜头表演方法

## 从情绪到行动

把结果性指令改写：

| 不可执行 | 可执行任务 |
|---|---|
| 更伤心 | 不让对方发现你要哭；逼他收回那句话 |
| 更愤怒 | 用最平静的方式让他服从；夺回房间主导 |
| 更自然 | 完成真实物理任务，只在必要时看对方 |
| 更搞笑 | 认真证明错误规则，绝不承认自己误会 |
| 更神秘 | 隐藏一个具体事实，同时试探对方知道多少 |

情绪可能作为行动结果出现，不要求演员直接展示标签。

## 场景分析

1. **规定事实**：之前发生了什么，此刻谁在场。
2. **目标**：对对手产生什么改变。
3. **阻力**：为什么现在做不到。
4. **策略**：人物依次尝试什么动作。
5. **转向**：哪条新信息/反应让策略变化。
6. **代价**：成功或失败会失去什么。
7. **身体任务**：收拾桌面、找钥匙、守住门口、避开目光等。

## 镜头尺度

- 全景可读身体、距离和环境任务；
- 中景适合手势、姿态与关系变化；
- 近景放大微小信息，也放大虚假和技术性分心；
- 极近景只保留部分信息，必须明确观众要读什么；
- 拍摄尺度变化时，目标不变，外部幅度和焦点精度可调整。

不要求演员“近景少演”，而是让其把注意力放到更具体对象，并维持真实行动。

## 喜剧

- 人物必须认真对待自己的目标；
- 笑点常来自人物逻辑与现实规则的冲突；
- 搭档间的地位、理解优势和节奏可以换手；
- 反应镜头要改变笑点解释，不是自动插入；
- 排练节拍，但保护首次听见关键信息的反应。

香港电影资料馆对周星驰与吴孟达的分析可作为搭档地位交换案例：[HKFA Newsletter](https://www.filmarchive.gov.hk/documents/6.-Research-and-Publication/06-03_newsletter/newsletter-105_e.pdf)。

## 悬疑与恐怖

导演需向演员说明：

- 观众此刻知道什么；
- 人物把异常解释成什么；
- 人物何时真正相信威胁；
- 哪条线索应可见但不被强调；
- 当前表演是遮掩、试探还是自我说服。

乔丹·皮尔在[DGA访谈](https://www.dga.org/craft/dgaq/issues/1704-fall-2017/gen-next-jordan-peele)中强调喜剧和恐怖都依赖精确追踪观众状态。

## 素人/本人出镜

- 给真实任务，不先追求背词；
- 把长口播拆成对具体对象说的短意图；
- 允许口头习惯存在，只删除影响理解的重复；
- 多拍听、想、做的过程，不只拍说；
- 若需重演真实事件，明确说明重演，不诱导旁人相信正在实时发生。

## 导演与安全

- [BAFTA Samantha Morton masterclass](https://www.bafta.org/media-centre/press-releases/bafta-masterclass-acting-with-samantha-morton/)强调自由、安全的环境、演员带来方案，以及乱序拍摄下的状态准备。
- [RSC rehearsal approaches](https://www.rsc.org.uk/learn/schools-and-teachers/teacher-resources/rehearsal-room-approaches-to-shakespeare)把世界、故事、人物、语言作为合作选择的入口。
- [National Theatre / Katie Mitchell](https://images.nationaltheatre.org.uk/uploads/2024/03/KatieMitchell-PractitionersinPractice-PDF-2024.pdf)提供把行动、摄影机、声音、剪辑和特写连起来的练习。
- 姜文公开课强调按演员能力工作、让演员舒服并保护安全：[中国新闻网](https://www.chinanews.com.cn/cul/2025/04-26/10406081.shtml)。

## Take设计

先拍基准版本，再只改一个变量：

- 策略：安抚 → 威胁；
- 地位：确信自己掌控 → 假装掌控；
- 速度：抢在对方反应前 → 故意留空等对方；
- 身体：靠近门守住出口 → 坐下拒绝参与；
- 信息：以为对方不知道 → 怀疑对方已经知道。

记录哪个版本改变了观众解释，而不是只选“情绪最大”的take。
