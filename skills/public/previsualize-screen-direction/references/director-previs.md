# 导演预演

## 预演类型

- **纸面分镜**：构图、顺序和信息；
- **俯视图**：空间、走位、轴线和设备；
- **手机走位视频**：节奏、焦段、光线和现场可行性；
- **动作预演**：地理、安全、角色分工；
- **技术测试**：滤镜、VFX、曝光、反射、同步；
- **表演排练**：目标、策略和身体任务。

## 哪些必须预演

- 不可重复或危险动作；
- 群体/车辆/儿童/动物；
- 复杂反射、长镜头和多部门同步；
- 关键揭示依赖构图；
- 场地时间极短；
- VFX/后期接口。

## 哪些要保留开放

- 真实人物首次反应；
- 纪录事件；
- 演员可能带来更好策略的对手戏；
- 天气和场地变化能提供新信息的部分。

《降临》使用分镜作为可视化而非束缚，并在样片不工作时修正视觉策略：[ASC](https://theasc.com/articles/arrival-cinematography-bradford-young)。

乔治·米勒强调单镜头服从整体视觉句子的流动：[DGA](https://www.dga.org/Events/2024/July2024/Furiosa_QnA_0524)。

## 现场优先级

1. 安全与同意；
2. 不可重复事实；
3. 核心表演与事件结果；
4. 空间和信息清楚；
5. 关键转向；
6. 保险覆盖；
7. 装饰镜头。
