# 真实个人IP原生数据契约

## 权威边界

| 事实范围 | 权威状态 |
|---|---|
| 人物、业务、定位、命名、受众、表达和验证判断 | 主体级不可变策略版本 |
| 平台身份与登录关系 | 账号与连接记录，仅作操作目标 |
| 发布前方案和盲预测 | Personal-IP preflight |
| 发布请求、尝试与结果 | Personal-IP 发布回执 |
| 平台结果与覆盖 | Personal-IP 指标和平台观察 |
| 预测—结果连接 | Personal-IP retrospective |
| 经多样本支持的方法规则 | Personal-IP evidence promotion |
| 视频制作过程 | Personal-IP video production ledger |

不要在 Skill 目录、聊天附件或任意工作目录创建平行的
`project.json`、`evidence.jsonl`、`metrics.jsonl`、`retrospectives/` 或
`method-promotions.jsonl`。方法输出可以是临时工作产物，运行真相必须进入上表对应的
原生服务。

## 范围规则

- 对话和分析可以覆盖当前所有相关账号；
- 主体策略是人物与业务真相源；
- `account_id` 只在发布、采集、浏览器控制和单帖指标等具体操作中选择目标；
- preflight 判断可以限定到 `subject × account × platform × content format`；
- 换平台或格式后，已有规则只是假设，必须重新验证。

## 真实素材纪律

1. 事实、证词、综合、推断、假设和未知分级；
2. 原始材料留在授权来源或用户产物中，策略只保存紧凑判断与不含凭证的引用；
3. 同意为 `withdrawn` 的证据不能进入新预写；
4. 未知保留为未知；
5. 真人纪录允许压缩时间，不允许伪造行动顺序、因果、身份或结果；
6. 涉及未成年人、客户、医疗、财务、住址等信息时使用 `restricted`。
7. Cookie、Token、密码、二维码、浏览器配置路径和完整私密原文不得进入模型上下文。

## 盲预测

进入盲预测前，`story.desire_behavior` 必须包含主体、欲望、当集目标、反作用、策略、可见行动、代价、状态改变、观众欲望，并通过静音行为测试。

每个指标至少冻结：

- 指标名；
- 基线；
- 预期方向；
- 最小可识别变化；
- 置信度；
- 失败信号。

结果缺失时写 `null` 并说明覆盖，不补0。发布回执不会回写 preflight。

## 方法升级

- 原生晋升门槛：至少3条来自不同发布回执的完整复盘；
- 多个时间窗的同一条内容只能算一个样本；
- 部分观察不能满足完整证据门槛；
- 可迁移判断仍需在未参与归纳的新内容、平台或格式上继续验证；
- 升级内容必须是 `if—then—because—exceptions—validation_check`，不能只写“以后加强开头”。

导出只是只读呈现，不得回写盲预测、发布回执、指标、复盘或已晋升证据。
