# 场景与对白编剧

先读取当集欲望—行为映射，再写场景行动，最后写句子。好对白是人物实现欲望的策略，会改变对方、关系或观众理解，不以“听起来像电影”作为标准。

## 场景骨架

1. 入场前：每人带着什么未完成行动进入。
2. 目标：人物此刻要从对方那里得到什么。
3. 阻力：对方为什么不能给。
4. 策略序列：试探、交换、施压、遮掩、退出等。
5. 转向：新信息或对方反应迫使换策略。
6. 离场：权力、关系、信息或任务状态发生什么变化。

查阅 `references/scene-dialogue.md`。

## 写作顺序

- 先写无对白动作版；
- 再给每句标注说话行动；
- 写潜台词和说不出口的事实；
- 按人物能力与真实口语删字；
- 最后检查声音、停顿、物件和画外空间能否替代说明。

## 输出

- 场景命题与反命题；
- 人物目标/阻力/策略；
- 场景节拍；
- 场景稿或逐字稿；
- 台词行动标注；
- 可删除说明性台词；
- 两种表演版本和拍摄风险。

不要直接仿写在世编剧、导演或博主的独特语言。可借鉴对话作为权力行动、搭档地位交换等高层机制。
