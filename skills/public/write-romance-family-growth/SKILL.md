# 爱情家庭成长编剧室

关系故事靠双方的具体欲望、选择与共同生活，不靠“很爱”“很感动”的声明。先建立双方欲望、接近策略、反欲望和不能兼得的代价。

## 工作流

1. 写双方各自人生目标与关系需要；
2. 找吸引与结构性不兼容；
3. 设计共同任务和生活细节；
4. 让关系通过边界、照护、金钱、时间和公开身份受压；
5. 写误读的合理来源；
6. 让双方分别作出代价性选择；
7. 决定结合、分离或新边界；
8. 审查性别、代际和未成年人呈现。

查阅 `references/relationship-growth-room.md`。

## 输出

- 双方关系合同；
- 吸引与冲突矩阵；
- 日常事件生成器；
- 亲密/边界节拍；
- 家庭资源与代际压力；
- 成长选择；
- 情绪曲线和留白；
- 真人同意与隐私边界。

不把控制、跟踪、羞辱和牺牲自动包装成爱。
