# 光色质感管线

## 五层

1. 场景、美术、服装和道具反射色；
2. 灯光光谱、色温、方向、软硬与对比；
3. 镜头和光学滤镜；
4. 传感器、曝光、色彩管理和监看Look；
5. 镜头匹配、二级校色、质感与交付。

后层不能无损修复前层的所有问题。

## 色彩规则

记录色相、饱和度、明度、面积、邻色、材质、人物归属和出现条件。颜色—情绪联想受文化与情境影响：[系统综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC12325498/)。

张艺谋团队在《坚如磐石》中用霓虹、雨、反射与暗前景服务人物内外层次，并从多种LUT收敛到少数Look：[ASC](https://theasc.com/articles/under-the-light-colors-of-crime)。

## 光线

- 先写光从哪里来、为什么存在；
- 通过方向和遮光建立体积与分离；
- 运动范围必须纳入光线设计；
- 多机位会限制塑形，需明确取舍；
- 亮不等于轻松，暗不等于犯罪。

## 扩散与质感

[Tiffen指南](https://tiffen.com/pages/diffusion-guide)显示不同扩散滤镜分别影响高光晕染、对比和表观锐度。测试：

- 裸镜基准；
- 实景亮点和逆光；
- 不同肤色；
- 关键文字/产品；
- 平台压缩；
- 叠加HDR/锐化后的副作用。

成片Look依赖摄影、美术、服装、化妆和后期协作，不是装一片滤镜：[ASC《王冠》](https://theasc.com/articles/regal-drama-the-crown)。
