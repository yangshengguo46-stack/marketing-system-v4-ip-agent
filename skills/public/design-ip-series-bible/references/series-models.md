# 长周期IP连续模式与案例

## 五线与六尺度

任何长期IP都用五条线观察：

| 线 | 负责 | 常见证据 |
|---|---|---|
| 事件线 | 外部目标和进度 | 完成、失败、资源变化、截止日期 |
| 人物线 | 内部信念/能力/身份 | 新选择、承认、边界、技能 |
| 信息线 | 观众等待解释的缺口 | 线索、误导、揭示、回收 |
| 情绪线 | 长期体验波形 | 压力、释放、希望、失落、余味 |
| 世界线 | 可复用的人物与规则 | 地点、关系、仪式、禁令、资源 |

同时标注：生命周期、季度、小弧、单集、场景、镜头。不要在生命周期层说“暗线是主线”后，就让某条日更没有当日事件。

## 五种连续模式

### 1. 连续成长型

- **强项**：真实进度、身份变化和高追更动机。
- **发动机**：目标—尝试—代价—新能力/新困境。
- **不可复位**：技能、资源、名誉或关系状态。
- **风险**：现实停滞时内容枯竭；为剧情伪造进度。

### 2. 情景喜剧复位型

- **强项**：低理解门槛、关系复用、可持续事件。
- **发动机**：稳定前提 + 角色盲点 + 可复发触发器。
- **允许复位**：表面秩序。
- **仍需积累**：观众对人物和关系的理解、偶尔的情感里程碑。
- **风险**：一个角色长期被羞辱，或每集靠同一种恶作剧。

### 3. 任务纪录型

- **强项**：现实证据天然构成进度和悬念。
- **发动机**：明确指标、截止日期、不可控现实、阶段复盘。
- **风险**：只报流水账；数据替代人物选择。

### 4. 情绪单元型

- **强项**：适合人物来访、城市故事、遗憾/治愈/勇气等母题。
- **发动机**：不同事件折射同一情绪问题。
- **积累方式**：主题变奏、主持人/主角理解变化和观众共同记忆。
- **风险**：模板化煽情、人物成为情绪素材。

### 5. 谜团元叙事型

- **强项**：单元事件和长期追问并存。
- **发动机**：局部问题闭环 + 元问题证据 + 人物道德选择。
- **风险**：无限挖坑、线索只靠台词声明、长期问题与人物无关。

## 案例转译

### 《唐人街探案》

可用作多尺度模型，不等于必须复制侦探题材：

- 单元层：每个案件提供当下调查与答案；
- 人物层：秦风、唐仁等人的能力、关系和道德问题；
- 信息层：更大的身份/组织/价值谜团；
- 世界层：不同城市、侦探网络和重复破案语法。

个人IP转译：每条解决一个小问题，同时留下“主角如何看待世界”的一次选择。长期暗线应积累证据，不能只在结尾放神秘人物。

### 疯狂小杨哥

把“一家人帮弟弟戒网瘾”理解为**情景喜剧强前提**更稳妥：

- 表层任务提供立即冲突；
- 家庭角色差异提供可复发关系引擎；
- 多数单集在混乱后回到可继续拍下一集的状态；
- 真正积累的是观众对家庭分工、人物盲点和喜剧节奏的熟悉。

因此，长期口号可以不真正线性完成，但每集必须出现不同策略与后果。不要把真实家庭持续困在固定羞辱角色中。

### 大圆哥

在公开材料不足以证明明确连续任务时，更适合作为**情绪单元型**研究：

- 每集人物/事件可变；
- 稳定的是遗憾、错过、亲情或克制余味；
- 账号长期线可能是主持者理解的变化，而非一个外部任务。

事实不足的部分必须标为分析假设。

## 第一季压力测试

圣经完成后回答：

1. 不靠热点能写出12条不同事件吗？
2. 主角失败、停滞或休息时，关系和世界线还能产出吗？
3. 哪些变量每集复位，哪些不可逆？
4. 观众错过三集后能否重新进入？
5. 季终回答了什么，又改变了哪个更大问题？
6. 若现实与原计划冲突，圣经如何容纳而不造假？
