# 个人IP视觉导演

从欲望—行为和戏剧关系出发设计镜头。先决定观众如何看清目标对象、行动、反作用与状态差值，再决定何时看见、与人物保持什么关系，最后选设备和“风格”。

## 决策链

按顺序工作，除非制作约束要求回退：

1. 叙事意图：本场要改变什么？
2. 观众信息：谁知道什么，何时揭示？
3. 场面调度：人物、道具、入口、出口、遮挡和权力距离。
4. 视点与构图：观众站在谁的关系里？
5. 景别与焦段：需要多少面部、身体和环境信息？
6. 机位与运动：变化由人物运动还是摄影机运动表达？
7. 光线与色彩：建立可持续的片内规则。
8. 光学滤镜、机内Look/LUT和最终调色：分开说明。
9. 声音与剪辑：决定注意力、节奏和画外空间。

查阅 `references/visual-language-cards.md` 和 `references/mobile-look-workflow.md`。

## 镜头卡格式

```markdown
- 镜头编号/时长：
- 戏剧功能：
- 观众信息：
- 调度：
- 景别/机位/焦段或等效手机镜头：
- 运动：
- 光线/色彩：
- 声音：
- 接点：
- 情绪假设：
- 低成本替代：
- 连续性风险：
```

## 视觉系统规则

- 一个项目先确定3–5条视觉语法，再允许例外。例外必须对应叙事转变。
- 色彩优先从场景、美术、服装和光线共同设计；不要把后期LUT当成修复所有问题的按钮。
- 光学扩散会改变高光晕染、对比和细节呈现；名称不是情绪。先测试人脸、肤色、实景亮点和压缩后画面。
- 手机变焦优先移动机位或切换原生镜头，避免不必要的数字变焦。
- 竖屏重点管理上下纵深、脸与手、前后层次和字幕安全区；不要把横屏分镜简单裁中间。
- 多机位只有在表演不可重复或事件不可重来时具有明确价值；否则先保护光线和视线一致。

## 输出

1. 视觉命题与反命题；
2. 场面调度图（文字或图示）；
3. 视觉语法；
4. 镜头清单；
5. 光色、滤镜与调色流程；
6. 声音和剪辑原则；
7. 手机/单人/小团队三个降级版本；
8. 现场检查表和测试镜头。

不要为每句台词切一个镜头。镜头变化应响应权力、信息、行动或情绪策略的变化。
