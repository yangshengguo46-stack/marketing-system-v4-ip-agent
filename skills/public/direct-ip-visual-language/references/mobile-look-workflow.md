# 手机竖屏视觉工作流

## 前期测试

在正式拍摄场地录制10–20秒测试，包含：

- 正面、侧面和逆光人脸；
- 最亮实景光源；
- 深色衣服和高饱和物件；
- 走动与快速手势；
- 字幕安全区；
- 上传平台后的二次压缩版本。

测试后再决定曝光、HDR/Log、锐化、降噪、光学附件和LUT。不同手机和平台处理差异大，不给统一数值。

## 竖屏调度

- 用前、中、后景创造纵深；
- 让脸、手和关键物件错开，不堆在画面中央；
- 角色地位可通过上下层级、靠近/离开镜头和前后遮挡改变；
- 预留上方平台UI与下方字幕/互动区；
- 两人对话若横向空间不足，可用前后站位和视线深度。

## 镜头选择

- 优先使用原生广角/主摄/长焦档位；
- 数字变焦前先问能否移动机位或后期轻裁；
- 自拍镜头易让脸和背景关系夸张，适合直接、迫近或喜剧性，不自动等于“真实”；
- 稳定器只在持续跟随能增加信息时使用；
- 手持必须有身体或注意力理由。

## 单人拍摄覆盖

最小覆盖：

1. 一个能看清动作地理的主镜头；
2. 一个承担关键证据的近镜；
3. 一个改变解释的反应或结果镜头；
4. 一段可用环境声。

若事件不可重复，先保护主镜头，不为装饰性特写错过结果。

## 低成本光线

- 先找窗、门、天花灯、屏幕和招牌等现实光源；
- 通过人物走位和遮光改变方向与对比；
- 白墙/泡沫板可回填，黑布/深色衣物可减光；
- 混合色温若是环境事实可保留，但要防止肤色无规则漂移；
- 夜景先确保人脸与关键物件可读，再增加彩色背景层。

## 色彩和调色

1. 锁定或稳定白平衡；
2. 正确曝光并保护肤色与高光；
3. 镜头匹配；
4. 建对比和黑位；
5. 建项目色彩规则；
6. 只在最后添加质感；
7. 导出后在目标手机、普通屏幕和平台上传版本复查。

禁止：

- 用重LUT掩盖白平衡错误；
- 每条视频换一套色彩语法；
- 把锐化、颗粒和暗角一起拉满；
- 未测试就叠加廉价扩散附件与手机自带HDR。

## 现场清单

- [ ] 画幅、分辨率、帧率和快门策略一致；
- [ ] 曝光/白平衡无自动跳变；
- [ ] 关键声音另录或有备份；
- [ ] 字幕和UI安全区；
- [ ] 动作、视线、道具和光线连续；
- [ ] 录5–10秒环境声；
- [ ] 拍结果镜头；
- [ ] 当场回看最亮、最暗和最快动作。
