# 导演、摄影、光色与镜头机制卡

## 导航

- 调度、空间、景别与主观层
- 权力、家庭与色彩系统
- 光线与“滤镜”分层
- 声音、剪辑与制作降级

## 先调度，后覆盖

场面调度至少标出：

- 人物目标与对手；
- 入口、出口、关键物件；
- 谁能看见谁、谁被遮挡；
- 人物距离何时改变；
- 哪个动作使权力或信息转向。

镜头只有在调度关系明确后才有功能。无调度的“高级运镜”通常只是摄影机在替人物表演。

## 空间清晰

借鉴黑泽明动作组织的专业分析：

- 先给地点、阵营和路径；
- 关键方向保持可读；
- 在规则被理解后，才能有意打乱方向；
- 天气、风、尘、门窗等环境元素可参与局势。

来源：[DGA《用心棒》放映分析](https://www.dga.org/craft/dgaq/issues/0603-fall-2006/screening-room-darren-aronofsky)；[ASC《乱》制作档案](https://theasc.com/articles/japanese-method-for-ran-kurosawa)。

## 景别与屏幕时间

希区柯克指出构图清晰度与一个镜头占据的银幕时间有关：复杂信息需要更清楚或更长的呈现。

- 短镜头只承担一个主要读取任务；
- 群像先建立地理，再切局部；
- 竖屏内小物件必须通过距离、运动或声音获得注意；
- 不用剪得快来掩盖信息不清。

来源：[ASC Hitchcock interview](https://theasc.com/articles/flashback-hitchcock-talks-about-lights-camera-action)。

## 镜头与主观层

《降临》的制作提供一种可迁移方法：

- 先定义“日常现实”和“记忆/主观层”的情绪命题；
- 为两层分别制定距离、镜头质感、运动和光线；
- 分镜用于对齐意图，但若样片不工作，允许根据dailies修正。

来源：[ASC Arrival cinematography](https://theasc.com/articles/arrival-cinematography-bradford-young)。

## 权力、家庭和阴影

《教父》的可迁移机制不是简单“压暗”：

- 家庭与权力是同一个戏剧问题；
- 顶光、阴影和控制性构图建立封闭规则；
- 视觉策略保持紧、简、可重复。

来源：[ASC The Godfather](https://theasc.com/articles/the-godfather-on-location-gordon-willis-cinematography)。

## 色彩系统

### 规则

1. 写颜色出现的叙事条件；
2. 同时设计美术、服装、光线和后期；
3. 限制最终Look数量；
4. 为规则准备一次有意义的破例。

《坚如磐石》经历多种LUT测试，最终仅保留少数Look；霓虹、雨、反射和暗前景围绕人物内外层次组织，而非随机“赛博朋克”。来源：[ASC Under the Light](https://theasc.com/articles/under-the-light-colors-of-crime)。

《影》把二元主题贯穿摄影、美术、服装与表演。来源：[ASC Shadow](https://theasc.com/articles/dual-nature-shadow)。

## 光线卡

每个场景写：

- 现实光源与方向；
- 主体/背景分离方式；
- 对比与曝光保护；
- 眼神光是否需要；
- 场景内颜色来源；
- 人物移动后光是否仍合理；
- 多机位是否破坏光线设计。

[Kodak filmmaker guide](https://www.kodak.com/content/products-brochures/Film/kodak-essential-reference-guide-for-filmmakers.pdf)把照明与二维画面的三维分离联系起来，并强调故事、导演、预算、镜头等共同决定风格。

## “滤镜”分层

不要混称：

| 环节 | 作用 | 需测试 |
|---|---|---|
| 美术/服装颜色 | 进入画面的真实反射色 | 肤色、背景分离、连续性 |
| 灯光色片/灯具色彩 | 改变光源颜色 | 显色、混光、频闪 |
| 光学滤镜 | 拍摄时改变进入镜头的光 | 高光晕染、对比、细节、鬼影 |
| 机内Look/LUT | 监看或编码转换/预览 | 色彩管理、曝光判断 |
| 最终调色 | 镜头匹配与叙事色彩 | 跨设备、压缩、肤色 |

[Tiffen diffusion guide](https://tiffen.com/pages/diffusion-guide)显示不同扩散滤镜分别影响高光晕染、对比和表观锐度；产品名不能直接翻译成情绪。

[ASC《王冠》制作](https://theasc.com/articles/regal-drama-the-crown)提醒，成片Look不是“放一个滤镜”即可获得，而是摄影、服装、化妆和布景的团队计划。

## 声音和剪辑

- 先建立空间声基线，再用缺失制造主观变化；
- 画外声可以引导视线或延迟揭示；
- 动作接点优先保护因果；
- 反应镜头只有在改变观众解释时使用；
- 音乐进入点写明“它提供人物未说出的哪一层”，否则暂不加。

## 三个降级原则

- 设备降级：保留视点和调度，牺牲复杂运动。
- 人手降级：保留主光方向和关键反应，减少覆盖。
- 时间降级：保留建立镜头、转向镜头和结果镜头，删除装饰空镜。
