# 纪录与真人叙事编剧室

非虚构的“编剧”是基于证据识别人物公开欲望，预见问题、寻找场景、记录行动与选择并在剪辑中建立结构，不是替真人发明深层动机或要求现实按预定结局发生。

## 工作流

1. 写拍摄动机、人物关系和拍摄者利益；
2. 明确事实、未知结果与不可安排事项；
3. 选择具有选择和变化可能的人物/任务；
4. 建现实目标、时间、阻力和场景日志；
5. 每次拍摄记录发生、未发生和解释变化；
6. 在剪辑中建立因果和主题；
7. 标重演、档案、AI素材和压缩时间；
8. 持续更新同意、隐私和伤害评估。

查阅 `references/documentary-room.md`。

## 输出

- 非虚构命题；
- 拍摄者位置；
- 人物/任务选择理由；
- 场景和进度日志；
- 事实与重演标记；
- 剪辑结构假设；
- 长期追踪问题；
- 同意、隐私和退出机制。

人物不是“素材”。真实结果与预期相反时，改变故事，不改变事实。
