# 真实个人IP原生校准契约

## 唯一运行状态

| 阶段 | 原生真相源 | 关键不变量 |
|---|---|---|
| 主体判断 | `personal_ip_strategy_versions` | 主体级、版本化、证据驱动 |
| 发布前判断 | `personal_ip_preflights` | 请求与回执不可变 |
| 发布 | `personal_ip_publish_receipts` | 初始请求不可变、尝试只追加、终态单调 |
| 指标 | `personal_ip_metrics` | 来源、观察时间、窗口与覆盖完整保留 |
| 复盘 | `personal_ip_retrospectives` | 连接一条发布与其原始 preflight、同回执结果 |
| 方法晋升 | `personal_ip_evidence_promotions` | 至少3条不同发布回执的完整复盘 |

不得另外创建 `project.json`、JSONL 台账或兼容导出目录。聊天历史不是运行状态，
账号ID也不是人物或对话权限。

## 范围

- 对话与组合分析默认覆盖授权用户的完整账号组合；
- 人物、业务和定位真相属于主体；
- 账号只作为发布、浏览器采集、桌面操作和单帖指标的目标；
- 单次判断仍需明确 `subject × account × platform × content format` 的适用范围；
- 换平台、格式或受众后，已晋升规则仍需重新做留出验证。

## 真实素材纪律

1. 事实、证词、综合、推断、假设和未知分级；
2. 原始材料留在授权来源或产物中，运行状态只保存必要引用与摘要；
3. 同意为 `withdrawn` 的证据不能进入新预写；
4. 未知保留为未知；
5. 真人纪录允许压缩时间，不允许伪造行动顺序、因果、身份或结果；
6. 涉及未成年人、客户、医疗、财务、住址等信息时使用 `restricted`。
7. 原始凭证、Cookie、Token、密码和浏览器配置路径永不进入模型证据。

## 盲预测

进入盲预测前，`story.desire_behavior` 必须包含主体、欲望、当集目标、反作用、策略、可见行动、代价、状态改变、观众欲望，并通过静音行为测试。

每个指标至少冻结：

- 指标名；
- 基线；
- 预期方向；
- 最小可识别变化；
- 置信度；
- 失败信号。

结果缺失时写 `null` 并说明覆盖，不补0。发布回执不会回写 preflight。官方累计
快照只能按原始语义保存；只有同一帖子连续、单调的相邻快照才能派生明确区间增量，
且必须标成 `partial`、`tracked_post_only`。

## 方法升级

- 至少3条来自不同发布回执的完整复盘；
- 同一帖子的不同观察时间窗只计一个支持样本；
- 部分指标或不完整复盘不能满足门槛；
- 晋升由确定性政策自动决定并保存决定回执；
- 可迁移判断还要用未参与归纳的新内容、平台或格式做回归；
- 升级内容必须是 `if—then—because—exceptions—validation_check`，不能只写“以后加强开头”。

只读导出不得改变任何运行状态，也不得把模型推断升级成已观察事实。
